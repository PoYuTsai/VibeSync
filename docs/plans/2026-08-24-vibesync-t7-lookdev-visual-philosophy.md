# Afterrain Optics

狀態：已由 Eric 於 2026-08-24 正式拍板並隨 `D-T7-LOOKDEV-01 Revision 1.1` 凍結；後續參數調校不得重開本文件的色彩責任、光學接力或四層介質。

`Afterrain Optics` 是 `Refracted Continuity` 的表面表達，不是新的敘事世界。空間由濕潤、折射與逐步乾淨的焦點建立：形體先像現實玻璃上的反光，之後才取得可辨認的邊、基線與產品平面。每一道遮擋都保留來源，每一次清晰都像經過無數次光學校正；完成品必須看得出頂尖影像設計者反覆推敲過每一毫米，而不是套上一層現成 glassmorphism。

色彩像有記憶的光源。現實端使用低彩度暖灰與雨後鈉燈殘光，解讀端收斂為冷靜銀灰，Coach 紫只在方向被看見時提供受控回應；高飽和橘不進入環境，只在真正行動的產品元件中短暫存在。每一種色相只有一份職責，飽和度、面積與亮度都必須以近乎偏執的精度校準，讓工藝感來自節制而非發光效果。

材質依可知程度改變。不可知不是黑霧遮住答案，而是表面失去方向與對比；可知也不是突然點亮，而是邊緣粗糙度降低、焦點平面變薄、文字回到真實產品尺寸。濕窗、銀線、產品玻璃與 Coach 介面應像同一束光在不同介質中的四種反應，經過大師級、耗時而細密的材質打磨，沒有任何一張卡片像被貼上去。

構圖由一條連續脊柱維持方向，其他平面只在需要成為目的地時靠近。尺度用來安排責任：姓名先於時間，訊號先於階段，下一步先於 Coach；背景資訊仍存在，但以景深、裁切與反射被克制地留在周邊。文字只作座標與證據，採稀疏、精準、可呼吸的排版；每一道 baseline 與每一個留白都應呈現無數小時的專業修整。

整體必須像一件研究脆弱人類訊號的觀測器：理性但不冷酷，電影化但不宏大，感性卻拒絕替任何人下結論。真正的高級感來自極少元素之間完美的材質接力；作品必須經得起逐格、近看與手機縮小三種檢查，呈現頂級工藝、痛苦精修與不容替代的視覺秩序。
