# Onboarding 鏡像卡＋分流按鈕說明 設計

**日期**：2026-08-07
**狀態**：已實作（本 branch，與圖鑑落地引導同批）
**源頭**：夥伴分析的規格（onboarding 問卷投入沒有回應）＋Eric 過稿升級版
**範圍**：純前端。不動 AI、額度、付費牆、Edge、資料庫、埋點字典、
`GrowthPreviewBuilder`。

## 相對原規格的三個升級（Eric 2026-08-07 拍板）

1. **回音卡 → 承諾卡**：原規格後半句五個目標全同一句（罐頭）。改為每目標
   一句具體的「教練會怎麼做」，一目標一組（粗體標籤＋承諾句）上下排。
2. **不用共用產生器**：文案放 `OnboardingQuestionnairePage.goalPromise`
   本頁對照表，不碰「關於我」共用的 `GrowthPreviewBuilder`；一目標一組
   也天然消滅頓號串接流水句問題。
3. **練習按鈕小字對齊真實落地**：「先在練習室把手感練起來」→
   「先抽一位練習夥伴，把手感練起來」——按下去到的是圖鑑翻牌，
   與落地 Sydney 泡泡前後接成同一句承諾。

## 過稿文案（改字要連動逐字測試）

| 目標 | 承諾句 |
|---|---|
| 想約得出來 | 教練會幫你盯時機——聊到什麼熱度、出現哪些訊號，就是開口約的時候。 |
| 想先能自在聊天，不要那麼緊繃 | 教練會先帶你把節奏放慢，不用急著接好每一句，聊起來自然不緊繃。 |
| 想讓對話更幽默、有來有往 | 教練會教你接梗和拋梗的位置，讓對話有來有往，不是硬擠笑點。 |
| 想培養穩定的親近感 | 教練會帶你把話題慢慢聊深，讓好感是累積出來的，不是忽冷忽熱。 |
| 想找到聊得來的對象、不設限交往 | 教練會幫你從每段對話看出誰真的聊得來，把力氣花在對的人身上。 |

分流頁小字：主按鈕「先幫你把她這輪的訊號讀懂」／次按鈕
「先抽一位練習夥伴，把手感練起來」。

## 沿用原規格的硬規則

- 沒選目標不出卡、無 fallback 空話（沒有投入就沒有東西可反射）。
- `AnimatedSize` 180ms 防置中跳動；`disableAnimations` 零秒；絕不用
  Timer/Future.delayed 當時間軸。間距收在卡片分支內，空狀態版面不變。
- 不加埋點（`onboarding_questionnaire_submit` 的 `goals_count ≥ 1` 與
  卡片出現完全等價）、不加頁、不加題、不碰資料寫入。
- 分流答案不寫 profile notes（2026-08-03 界線）。
