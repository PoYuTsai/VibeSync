### 2. 現況（main `38ab7dbb`）

- v2 實際送出的提示詞有 48,842 字元，其中靜態底座 34,496，沒有雜湊鎖；只有舊版 v1 有鎖。

### 3. 模型：Sonnet 5 換 5.5

5.5 跟 Sonnet 5 同價，但有三個不相容的地方，直接換名字會壞：

- 不接受 `thinking: {type: "disabled"}`、強制 `tool_choice`、非預設 temperature 和 assistant prefill，會回 HTTP 400。思考只能用 `between_tools`（不先思考）或自適應。
- 自適應思考會吃掉 `max_tokens`。`_shared/model_request_params.ts` 的 `maxTokensFor()` 會另加 `SONNET_5_5_THINKING_HEADROOM_TOKENS`（4000）。
- 多一層安全過濾：回 `stop_reason: "refusal"` 並帶類別（例如 `general_harms`），可能誤擋正常的曖昧內容。

每個呼叫換之前都要過四個門檻：

- **效能**：等待時間中位數不比 Sonnet 5 慢。
- **品質**：不比 Sonnet 5 差，差距要大過同版本重跑的自然起伏才算改善。截圖辨識看左右判對、漏抓和多出訊息。分析另外自動數三項：推薦回覆是否遠比她長、是不是又一個問句、有沒有放進用戶自己的事。這三項只當評分，不進提示詞。
- **成本**：每次呼叫多花不超過 15%，思考用掉的 token 也算進去。
- **相容**：0 次被拒絕的請求；一般語料 0 次拒答；曖昧和性相關的探測句另外人工看。

### 4. 知識點（只呈現）

- 伺服器在判斷之後另外送一個新的串流事件，名稱實作時再定。App 新版把它顯示在判斷卡正下方；舊版 App 會忽略不認得的事件，實作時要在 `analyze_stream_client.dart` 確認。
- 挑選順序：判斷種類 → 先別回的動作 → 伺服器自己算的訊號 → 模型給的教練動作類型。第一批 13 條規則在 23 個黑箱案例都配得到一條，22 案重跑三次都選同一條；這一版新增的 2 條還沒跑過黑箱。
- 文字：我們自己改寫，45 字以內，要過教學契約與禁用詞稽核。不引用課程原文、不顯示課程章節編號；只寫用戶可以怎麼做，不替她分類，不寫「永遠」「絕不」。
- 送出前跟推薦回覆比對。推薦回覆本身違反這條知識點時就改選別條，例如知識點說先別再問，推薦回覆卻又是問句。

**不能呈現的內容**

- App 已明文禁止的寫法：假定她會同意、「週四晚上七點，我訂位」、「別讓拒絕你變成零成本」、把「當天有事再跟我說」當錯、把「先從朋友開始」讀成假拒絕、把她回「那算了」或嘴上否認讀成其實想要。
- 人格或性別標籤：Alpha／Beta、紅藥丸、Hypergamy、SMV、廢物測試、IOI、AMOG、ASD、供養者、推拉、試窗口。這些字出現在截圖分析旁，App 就像把妹工具。

### 5. 接法

| 現在的風格 | 改成的白話名 | 什麼時候出現 |
|---|---|---|
| 延展 | 接住再延伸 | 幾乎都出；主力，推薦率八成 |
| 共鳴 | 先站她那邊 | 她講心情時優先；剛開場不出，免得變低姿態 |
| 幽默 | 一起笑 | 她心情差時不出；她開玩笑鬧你時優先 |
| 調情 | 往曖昧走一步 | 只在她開始反問你、見過面或她稱讚你之後才出 |
| 冷讀 | 觀察加猜測 | 只在她給了具體材料時出；只有招呼、確認行程時不出 |
| 沒有 | 分享自己（新增） | 黃燈、她只答不問、往回看九則你自己的事不到三則、她問到你本人或問你意見時 |
| 沒有 | 推進（新增） | 還沒把握時先鋪墊：提一個具體的店或活動，不提時間。她接了或亮綠燈，兩輪內講時間地點，再問她方不方便 |

- **第一步，不改提示詞**（Eric 10/4 核准的 B 案）：伺服器依情境決定出哪幾種、改白話名；模型自評「此刻不適合」0 分的卡直接不出。ADR #25 與付費文案隨實作改。
- **第二步，結構刀**（改提示詞，用開關切換）：模型照「這輪需要什麼」直接寫 2 到 4 張，補上分享自己和推進；她問到用戶本人時留空格，填好才能複製。
- **共用規則**：長度跟她差不多、她回得淡就換話題不硬問、她越喜歡你玩笑越少、曖昧要等她先有訊號。伺服器算得出來的由伺服器檢查，例如把長度遠超過她的卡往後排，門檻用黑箱校準。
- **免費方案**：「推薦卡加一張對照」，因為付費推薦有兩成落在免費看不到的接法。改之前要先補免費方案的黑箱，目前一筆都沒有。
- 標籤和理由裡的術語，例如調情卡 78% 寫「推拉」，第二步一併清掉。
