## 0. 一句話

> 男主在真實 App 送出訊息後沒有回音，被那片沉默拉進禁空間持續下墜；下墜的每一秒冰霜從指尖往身上爬，他越僵硬掉得越快；Sydney 帶著橘色的火追下來，必須在他凍成會摔碎的雕像前碰到他——而火一碰冰就會被吃掉。

寓意對照（只有這兩個）：
- 冰 ＝ 聊天冷掉、怕說錯話而僵住。
- 火 ＝ 品牌橘 ＝ 她期待你的回覆。
- 天秤／胸架／Key／封印書：不進影片，留 App 與網站功能區。

倒數計時的尺規：**冰爬到哪裡**。指尖 → 手腕 → 手肘 → 肩 → 胸口。全片觀眾只要看這一件事就知道剩多少時間。

## 2. 60 秒節奏表

格式：`START → CAMERA → ONE ACTION → END → CUT MATCH → AUDIO`
單元 U = 一次獨立生成或一段真實素材；接縫都落在「同一重力方向＋同一移動物」。

### U1｜0–8s｜網站就是第一鏡（跳框）
- START：真實網站 hero 畫面，靜止，與訪客剛才看到的網頁一模一樣。
- CAMERA：緩慢推進右側傾斜手機；推到手機占滿畫面時，手機畫面切成真實 App 首頁截圖。
- ONE ACTION：手機玻璃邊緣起霜，霜沿玻璃往中心爬；橘色入口鈕是唯一沒結霜的地方。
- END：畫面整片是起霜的手機玻璃，只剩橘鈕發光。
- CUT MATCH：橘鈕的光 → U2 第一幀畫面中央同位置的橘點。
- AUDIO：房間靜音 → 玻璃結霜的細碎脆響 → 一聲低頻「拉走」。
- 註：0–4s 可以直接用真實網頁錄屏＋後期推鏡，不必生成；4–8s 生成。

### U2｜8–22s｜真墜落＋倒數開始
- START：第一人稱，雙手在畫面下緣，深紫黑玻璃牆面在視野兩側；畫面中央遠處一個橘點。
- CAMERA：第一人稱垂直俯衝，近牆高速向上刷；中段切一次第三人稱側面遠景（人物小、井道深），再切回第一人稱。
- ONE ACTION：**冰從指尖爬到手腕再到手肘**；手指越來越張不開。橘點沒有變大（他在追不上）。
- END：第一人稱，雙手手肘以下全白，橘點仍在遠處。
- CUT MATCH：橘點 → U3 首幀 Sydney 掌心的火（同位置、同大小）。
- AUDIO：風壓持續、衣物拍打、冰在皮膚上「嗒嗒」延伸的高頻；沒有音樂。
- 註：15 秒循環從這段剪，取沒有切鏡的第一人稱區間。

### U3｜22–36s｜Sydney 追到、接觸、火碰冰
- START：Sydney 視角／過肩：她單手貼牆面導軌向下滑，另一掌心一團橘火；抬頭看見上方一個白色僵直的人影快速放大。
- CAMERA：過肩追下 → 兩人側面伴墜（速度匹配）→ 接觸瞬間切極近景（手對手）。
- ONE ACTION：她抓住他結冰的手臂；**火碰冰，蒸氣炸開**，兩人在白霧裡失控翻滾，但碎屑、頭髮、衣物始終向上（重力不丟）。
- END：白霧散一半，兩人抱成一團繼續往下，她掌心的火明顯變小，他胸口的冰開始有裂紋。
- CUT MATCH：兩人抱團的剪影 → U4 首幀極遠景中的那個小點。
- AUDIO：接觸瞬間的瞬態撞擊＋蒸氣噴發；之後風壓變悶（在霧裡）。
- 註：這是身份混合最高風險段；接觸用「手對手極近景」單獨一鏡，不讓模型在遠景自己發明抓握。

### U4｜36–48s｜極遠景證明 → 火贏
- START：幾乎固定的極遠景，井道頂端到底端全在畫面裡，兩人是一個小點：一半白一半橘。
- CAMERA：固定不動 3–4 秒（證明「真的掉很遠」），然後急推進到近景。
- ONE ACTION：小點裡的橘光突然放大，**冰殼整個碎開**，碎冰向上飛散；兩人下墜速度肉眼可見地慢下來。
- END：兩人幾乎懸停，他手指重新能動，她的火只剩一點但還在；他們對看一眼。
- CUT MATCH：他看她的視線 → U5 首幀手機畫面上她的頭像。
- AUDIO：極遠景只剩低頻和極輕的風；冰碎是全片最大的一聲；之後突然安靜。

### U5｜48–60s｜回到真實 App（不生成）
- START：真實 App 聊天畫面截圖／錄屏，男主稍早送出的那句訊息還停在那裡。
- CAMERA：靜止手機畫面，最後拉出成為網站 hero 的手機框。
- ONE ACTION：**她的回覆進來**（真實 App 通知／訊息氣泡，錄屏）。
- END：回到網站 hero 構圖，標語「配對成功只是開始／讓她期待你的回覆」，App Store 鈕。
- CUT MATCH：頭尾都是網站 hero——訪客從哪裡進來就回到哪裡。
- AUDIO：一聲真實 iOS 訊息提示音；然後品牌收尾音。
- 註：需要 Eric 提供真實錄屏；不得自創訊息內容或假 UI。
