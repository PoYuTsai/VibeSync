## 5. 坑

- R13 是字串比對：定稿句要逐字（含「，」「；」），只有半形／全形同一符號的寬度與空白會折疊，引號不折疊（Eric 在 #64 改的，避免「不要『逼問』」與「不要逼問」撞 key）；自己改一個字就找不到。
- R12 的 finding key 含片語：把禁用詞從一個 id 搬到另一個 id 會被當成新發現；直接刪或改寫，不要搬。
- 條目展開後 summary 仍顯示在標題下，內文第一段不要跟 summary 同一句。
- 章 id 不能改（教練深連結只指章 id）；區塊 id 可改但閱讀進度以區塊 id 為 key。
- 第 7 冊 7.1 有 stageFunnel（`ebook-7-c1-funnel`）用「消極／普通／積極」當 stageName 與 targetLabel；燈號名稱若改，漏斗一起改，Dart 漏斗契約只查目標章存在。
- `tools/content/__pycache__` 不要 commit；Stop hook 會催 commit／push，在這條分支照做。
- 上下文太長會被壓縮：中途結論寫進 scratchpad notes 或這份文件。
