## 0. 摘要

一句話：**流程不動**（只翻一次、停住等點擊、收進那一格都保留），只把強度往上推：光要亮、要有層次；SR 要有自己的高潮；每個重要動作都要聽得到。

| 項目 | V3（現在） | V3.1（本規格） |
|---|---|---|
| 揭曉長度 | N／R／SR 一律 2.7 s | N／R 2.7 s 不變；**SR 3.6 s**（多出藍→金升階和「SR 時刻」） |
| 光 | 只把徽記和外框染色，光暈弱 | 加泛光（預先模糊好的光暈貼圖、疊加混色），蓄力起點徽記白閃 |
| 翻牌高潮 | 細光刃 250 ms、星塵 20／26／34 顆 | 光刃加寬；R／SR 加衝擊波光環；SR 再加全螢幕閃光、鏡頭推近、往上噴的金粉 |
| 稀有度牌 | 24 px 小膠囊，從 1.6 倍縮回 | 32 px 膠囊，加速砸下再回彈（SR 從 2.2 倍）；SR 落地有光環和畫面微震 |
| 星星 | 16 px，逐顆放大 | 20 px，每顆亮起時閃一個十字星光 |
| 收卡 | 小光點加 10 個殘影點 | 金色彗星光尾，落位時放射狀爆光加兩圈光環 |
| 聲音 | 一條配樂三種共用，染色、牌、星星都沒有自己的聲音 | 同一段音樂，依稀有度**烤進不同重音**：升階音、SR 號角、牌落地悶響、星星鈴聲 |
| 角色登場 | 照片＋資訊欄 | 停住前，卡片下方浮出她的自我介紹（`selfIntro`，打字效果） |
| 收藏回饋 | 光球飛進那一格並發光 | 新卡掛「NEW」；落位時圖鑑「已收集」數字才 +1 並跳一下；重複角色寫「已收藏」 |

需要 Eric 決定的事集中在 §1。§4–§9 是建議做法與數值，§11 是怎麼分刀。

## 2. 差距在哪裡（對照結果）

### 2.1 跟參考片逐拍對照（SR）

### 2.2 聲音（125 ms 窗 RMS）

兩邊用同一支程式量（轉單聲道後算 RMS）。我們這邊照 app 的音量與觸發時點合成（§14），揭曉起點 R0 從按下後 0.5 s 算。

| | 參考片 | 我們（main，SR） |
|---|---|---|
| 等待 | 全靜音 | 只有按下時的咻聲（照 `docs/bug-log.md` 2026-07-16，維持） |
| 蓄力平台 | −31.7 dB（2.6–3.9 s 中位數） | −29.4 dB（R0 到 R0＋600 中位數） |
| 翻牌高潮 | −13.5 dB，比蓄力高 **18.2 dB** | −17.6 dB，只高 **11.8 dB** |
| 稀有度牌 | −19.1 dB，一個重音 | 沒有（牌出現時 −30 dB 上下） |
| 星星 | −16.0 dB，一串鈴聲 | 沒有（配樂剛好有個 −25.8 dB 的小起伏，不是設計的） |
| 落位 | −22.8 dB | −23.2 dB（收卡音，做到了） |

V3 §2.2 用 `astats` 量，絕對值比這次低約 3 dB，各段之間的落差一致。本規格的目標只看落差。

### 2.3 跟市面抽卡遊戲比

拿幾類常見做法比：原神、崩壞：星穹鐵道用流星或光的顏色預告稀有度；爐石戰記開卡包時，卡片翻開前先發出稀有度的光，傳說卡翻開有專屬音效；FGO 召喚有金色、彩色的光環；寶可夢 TCG Pocket 的閃卡反光跟著手機傾斜；戀與深空這類乙女遊戲抽到高稀有度時，角色本人有一段登場演出。差距集中在五件事：

1. **升階要停一下、要有聲音**：每升一階都有獨立的一拍和音效。我們藍和金只隔 0.25 s，也沒有聲音。
2. **高潮要疊層**：背景換色、放射光、衝擊波、遠近粒子、全螢幕泛光、鏡頭推近，通常好幾層一起。我們只有光刃、十字光、星塵。
3. **稀有卡要明顯不同**：普通卡快、樸素；稀有卡更長、更亮、更響。我們三種同一條時間軸、同一條配樂。
4. **角色本人要登場**：一句話、一段語音或會動的立繪。我們只有靜態照片。
5. **收藏要有回饋**：NEW、收集進度、重複角色的處理。我們只有落位發光。

我們比市面好、要保留的：**稀有度誠實**（不做「先假裝普通再變稀有」的升格演出）、按下到停住最快 3.2 s、整套對拍震動、reduce-motion 與 VoiceOver 版本、光球飛進真的那一格。

## 3. 目標（驗收用）

| 面向 | 目標 |
|---|---|
| 流程 | 不變：只翻一次、停住等點擊、收卡飛進那一格、稀有度只升到真實的那一階 |

| 效能 | 沿用 V3 §12 的規則與驗收方式；新增的層照 §9 |
| 無障礙 | reduce-motion 沒有儀式畫面，也沒有閃光、震畫面、數字跳動；VoiceOver 在停住時讀得到「新角色」與第一句話 |

## 4. 時間軸（以 R0＝揭曉起點為 0，單位 ms）

| 徽記白閃（新） | 560–720 | 560–720 | 560–720 |
| 銀光脈衝 | 700–800 | — | — |
| 染藍 | — | 600–720 | 600–720 |
| 藍色蓄力 | — | 720–1100 | **720–1300** |

收卡（以 A0＝點擊為 0）：`_archive` 從 550 ms 拉長到 **700 ms**，落位仍在 450 ms，多出來的 250 ms 給落位爆光與兩圈光環（§5.11）。

## 5. 視覺加強

顏色一律收在 `lib/core/theme/practice_reveal_palette.dart`；光暈不用 `MaskFilter.blur`（V3 §12），改用預先模糊好的貼圖＋疊加混色（`BlendMode.plus`）。

### 5.1 泛光（全部稀有度）

- 新素材 `practice_reveal_bloom.webp`：512×512 白色柔光（離線高斯模糊）。畫在卡片後面與前面兩層，大小 1.6×卡片，依主題 `glow` 染色。
- 後層 α：蓄力 0 → 0.25；染藍峰值 0.6（120 ms 內）→ 0.35；SR 染金峰值 0.7 → 0.45；翻牌峰值 N 0.30／R 0.50／SR 0.80，之後 400 ms 退回 0.25。
- 前層只在翻牌峰值前後 300 ms 出現，α ≤ 0.35，免得蓋掉照片。

### 5.2 徽記白閃

560–720 ms：徽記遮罩填白，α 0 →（600 ms）0.9 →（720 ms）0，疊在現有的徽記光上（這時徽記光已因蓄力升到 0.8）。三種稀有度都一樣，不洩漏稀有度；R／SR 緊接著染藍，N 接 700 ms 的銀光脈衝。

### 5.3 升階粒子

- R 720–1100、SR 720–1800：16 顆小光點沿卡片左右邊緣往上漂，主題星色（藍段藍、金段金），1.5–3 px，壽命 600–900 ms。
- 跟 V3 的星塵一樣用時間解析計算，零 Random。

### 5.4 光刃與十字光

| | V3 | V3.1 |
|---|---|---|
| 直光刃外暈 | 最寬 0.5×卡寬，250 ms | N 0.6×卡寬、R 0.7×、SR 0.8×；N／R 280 ms、SR 350 ms，後段快收，照片很快露出來 |
| 直光刃核心 | 2 px → 1 px | 3 px → 1 px |
| SR 橫向十字 | 0.9×卡寬、核心 3 px、外暈 24 px、180 ms | 橫跨整個螢幕（1.2×螢幕寬，兩端各 15% 漸隱）、核心 4 px、外暈 40 px、500 ms |
| SR 斜向光芒（新） | — | 45° 與 135° 各一道（合成 X 形），長 0.9×卡高，300 ms |

### 5.5 衝擊波光環（新 `PracticeRevealShockwavePainter`）

- 圓環半徑 0.35×卡高 → 1.3×卡高（easeOutCubic），線寬 12 px → 1 px，α 0.85 → 0，主題 tint，用漸層線條畫（不模糊）。
- N：不加。R：翻牌峰值 1 圈（400 ms、終點 1.1×卡高）。SR：升金 1 圈（終點 0.9×卡高、350 ms）＋翻牌峰值 2 圈（相隔 120 ms，各 500 ms）＋牌落地 1 圈（以牌為中心，半徑 20 → 60 px，300 ms）。

### 5.6 星塵與金粉

- 爆發星塵：N 20 → 24、R 26 → 36、SR 34 → 60 顆。
- SR 金粉噴泉（新）：40 顆從卡片下緣往上噴，初速 300–520 px/s、重力 600 px/s²，壽命 900–1200 ms，在 R0＋3300 前全部燃盡。
- 粒子改用一張預先做好的光點貼圖，以 `Canvas.drawRawAtlas` 一次畫完（現在每顆各建一個漸層 shader）；數量上限見 §9。

### 5.7 SR 時刻：閃光與鏡頭

- 全螢幕閃光：翻牌峰值時白色疊層 α 0 →（40 ms）峰值 →（300 ms）0；峰值 SR 0.30、R 0.15，N 沒有。每次揭曉最多這一次。
- 鏡頭推近：卡片與它前後的特效層包成一組（「舞台」，不含模糊背景），以卡片中心為原點縮放：SR 1.0 →（2050–2350，easeOutCubic）1.06 →（2350–2900，easeInOutCubic）1.0；R 1.0 → 1.03 → 1.0（1350–1800）；N 沒有。
- 牌落地微震（SR）：舞台水平位移 3 px·e^(−t/40)·sin(2πt/40)，t 是落地後經過的 ms，160 ms 後歸零。

### 5.8 立體感

- 等待呼吸：上下 ±3 px → ±5 px，左右微擺 ±2° → ±4°。
- 蓄力姿態：yaw −8° → −12°、pitch 6° → 9°、scale 0.92 → 0.90。
- 卡片厚度：|yaw| 在 60°–120° 之間時，側邊畫一條 5 px 的深色金屬漸層，翻牌那一刻看得出是一張有厚度的卡。

### 5.9 稀有度牌（E3＝A）

- 膠囊高 24 → 32 px，字級同比放大；SR 用金屬金漸層加一道反光。
- 砸入：牌出現後 60 ms 內，從 N／R 1.6 倍、SR 2.2 倍加速（easeIn）縮到 1.0＝**落地**，再用 160 ms 回彈 1.0 → 0.95 → 1.0；不透明度前 40 ms 從 0 到 1；落地瞬間加一道投影。縮放原點放在牌的左上角，放大時往卡片內側長，不會超出卡片。現在是 250 ms 的 easeOutBack，看起來是「彈出」不是「砸下」。
- 落地那一刻：觸覺（從牌出現挪到落地，晚 60 ms）、悶響（§6.2）；SR 再加 §5.5 小光環與 §5.7 微震。
- V3 的規則不變：牌在烙印前不存在，出現第一幀就是正確稀有度；牌與資訊欄都在卡片範圍內。

### 5.10 星星

- 16 → 20 px，間距 4 → 5 px。
- 每顆：scale 0 → 1.35 → 1.0（220 ms，現在峰值 1.25）；同時在星星位置閃一個四角十字星光貼圖（新素材 `practice_reveal_sparkle.webp`，直徑 28 px，α 0.9 → 0，250 ms，轉 30°）、噴 6 顆小光點（300 ms）。
- 只畫亮星（V3 D6）不變。

### 5.11 收卡光尾與落位

- 光尾：10 個殘影點換成一條連續的彗星尾。取飛行路徑 t−0.4 到 t 之間 24 個點，連成由粗到細的帶狀（光球端 12 px 漸細到 0），顏色從主題 `orb` α 0.9 到透明，疊加混色。
- 光球：外暈半徑 ×1.4，加兩道旋轉小光芒；沿途星點 8 → 14 顆。
- 落位（450 ms 起）：8 道放射光（長 0 → 48 px → 0，260 ms）＋兩圈光環（450–650、500–700 ms）。那一格原本的發光不變。

### 5.12 角色第一句話（E4＝A）

- 內容：`PracticeGirlProfile.selfIntro`（100 位都有，14–25 字），13 px，最多 2 行，超過用省略號。
- 位置：卡片下緣與底部提示字之間，置中、最寬等於卡寬；半透明深色小對話框（底下已經是模糊背景，不再加 `BackdropFilter`），上緣一個指向卡片的小尖角；離卡片、離提示字各至少 8 px。390×844 那裡約 90 px、375×667 約 83 px，兩行（約 58 px）都放得下；空間不夠兩行就只顯示一行，連一行都不夠就不顯示（VoiceOver 照樣讀）。等待字樣在 R0＋200 前已淡出，不會重疊。
- 動畫：時間軸「第一句話」那段逐字打出（0.5 s），停住前打完，停住後靜止。
- VoiceOver：停住時整層按鈕的 label 接上這句話。

### 5.13 NEW 與收藏回饋（E5＝A）

- 判斷：圖鑑頁送出抽牌時（一般抽與 SR 券都一樣）記下當下的已解鎖集合；揭曉的角色不在裡面就是新卡，透過新的 `isNewProfile` callback 告訴儀式。抽牌中離開圖鑑又回來（沒有那份紀錄）就當作不是新卡，寧可少掛、不錯掛。
- 新卡：稀有度牌旁邊掛「NEW」小標（沿用 `practice_room_entry_card.dart` 的 NEW 樣式），跟著牌砸入、晚 150 ms；VoiceOver label 加「新角色」。
- 收集數字：抽中後圖鑑的已解鎖數字會先在儀式底下更新，所以儀式期間標題先顯示抽之前的數字；光球落位時才換成新數字，同時 scale 1 → 1.25 → 1、顏色閃一下主題色（300 ms）。重複角色數字不變、不跳。

## 6. 聲音加強（E2＝A）

### 6.1 配樂檔

- 三條：`practice_draw_reveal_bed_v7_{n,r,sr}.m4a`，由新產生器 `tools/practice-draw-audio-v3/make_audio_v3_1.py` 從 git 取 bed v4 與紙聲（main `2aae192`，同 V3 第三刀），重跑逐位元相同。
- 音樂本身同一段：N／R 跟 bed v6 一樣取 bed v4 的 4.95–8.25 s（高潮在 1.35 s）；**SR 往前多取 0.7 s**，取 4.25–8.25 s（4.0 s），同一個高潮就落在 SR 的 2.05 s。多出來的 0.7 s 是 bed v4 原本「屏息」那段（4.4–5.2 s 程式合成的長音），沒有全頻重音（v4 的重音在 3.32／6.48／8.52 s）。三條都在 v4 的 8.25 s 收掉（N／R 2.9–3.3 s、SR 3.6–4.0 s 淡出），一樣避開 8.5 s 那記落定重擊。
- 翻牌紙聲照舊混在翻牌峰值（N／R 1.35 s、SR 2.05 s）。
- 響度：N／R 維持 bed v6 的 −17.2 LUFS；SR 版把高潮前壓低 2 dB（只動音量包絡，不換音樂），加上號角讓高潮的落差達到 §3；三條 true peak ≤ −1 dBTP，必要時只在高潮那 0.3 s 用限幅器。
- 大小：bed v6（3.3 s）是 69 KB；三條 v7 約 220 KB，扣掉移出的 v6，音效資料夾從 197 KB 變成約 350 KB。

### 6.2 重音（全部程式合成，烤進配樂檔）

照 `docs/bug-log.md` 2026-07-16：只用有音高的音，能量壓在 6 kHz 以下，不用寬頻噪聲（那就是「西西簌簌」的來源）。手機喇叭 200 Hz 以下幾乎出不來，低頻層一律加 2–4 次諧波（做法同 bed v4），驗收看手機近似響度。

| 重音 | 用在 | 時點（R0 起算） | 做法 | 響度 |
|---|---|---|---|---|
| 升階藍 | R、SR | 600 | E5＋B5 正弦，6 ms 起音、300 ms 指數衰減 | 比當下配樂高 ≥ 4 dB |
| 升階金 | SR | 1300 | C6＋G6＋C7 鐘聲泛音＋70 Hz 低頻一擊（80 ms） | 比升階藍再大 3 dB |
| SR 號角 | SR | 2050 | C 大三和弦（C4 E4 G4 C5），諧波只到 4 kHz，20 ms 起音、700 ms 衰減，加 45 Hz 低頻 250 ms | 跟壓低 2 dB 的蓄力一起，讓高潮比蓄力高 ≥ 16 dB |
| 牌落地 | 全部 | N／R 2060、SR 2760 | 180 Hz → 90 Hz 下滑正弦 120 ms（SR 加一層 C3） | 比當下配樂高 ≥ 4 dB；SR 再大 3 dB |
| 星星 | 全部 | N／R 2150＋80·i、SR 2850＋100·i | C6／D6／E6／G6 依序，各 150 ms | 每顆比前一窗高 ≥ 4 dB |
| 落位 | 全部 | A0＋450 | 沿用 `practice_draw_archive_v3.m4a`，不改 | — |

為什麼烤進配樂、不另外播短音效：V3 §8.1 說過，audioplayers 每次起播的延遲不一樣（數十 ms），80–100 ms 間隔的星星鈴聲另外播一定會糊。烤進同一條配樂，時點就跟畫面一樣準。

### 6.3 介面與播放

- `PracticeDrawSfx.playRevealBed()` 改成帶稀有度：`playRevealBed(PracticeGirlRarity rarity)`。
- `preloadReveal()` 照舊在按下抽牌時呼叫（那時還不知道抽到什麼）：三條 bed 各載一個 player（每條 < 90 KB）＋收卡音；抽中後只從頭播那一條。
- 等待期間照舊只有一次性咻聲；停住期間不加循環音，讓配樂自然收尾。
- bed v6 在 v7 上線那一刀移出 bundle（git 歷史保留）。

### 12.2 新測試要釘住的行為

1. **時間軸**：`standard` 與 `sr` 各自的節點嚴格依序、都在 `revealMs` 之內；`standard` 的值等於 V3。
2. **只翻一次**：兩條時間軸都每 50 ms 取樣，正面出現後卡背不再出現。
3. **稀有度誠實**：N 全程銀、R 不出現金、SR 先藍後金（兩條時間軸都驗）；徽記白閃三種都一樣。
4. **閃光安全**：任一 1 s 窗內閃光峰最多 2 個；全螢幕閃光峰值 SR ≤ 0.30、R ≤ 0.15、N 恆 0。
5. **停住靜止**：鏡頭 scale 在停住前回到 1.0、微震歸零；所有粒子、光環、打字效果在停住前結束；`pumpAndSettle` 收得了。
6. **牌**：烙印前不存在、第一幀就是正確稀有度、回彈不小於 0.95、最後 1.0、任何時刻都在卡片範圍內。
7. **NEW**：只有新卡有；重複角色有「已收藏」、沒有 NEW；抽牌中離開又回來（沒有紀錄）不掛 NEW。
8. **收集數字**：儀式期間顯示抽之前的數字，光球落位時才 +1 並跳一下；重複角色不跳；reduce-motion 直接更新不跳。
9. **第一句話**：顯示 `selfIntro`、最多 2 行、停住前打完；375×667 與 390×844 都不跟卡片、提示字重疊；VoiceOver label 接上這句話。
10. **聲音**：抽到哪個稀有度就播那一條；按下時三條都預載；收卡音不變；全程不呼叫 `playWaitingLoop()`。
