## 0. 一句話

> 男主在真實 App 送出訊息後沒有回音，被那片沉默拉進熄掉的螢幕之井持續下墜；井壁的黑螢幕一片片剝下來貼到他身上，跟霜一起把他包成越滾越大的玻璃冰繭；井底的橘點衝上來——是 Sydney，她踩過的每片螢幕都亮起來；她站上冰繭用火點亮它，但繭長得比火快，她的火越來越小；繭裡他的手指自己動了、伸出去碰她的手，裂紋從裡面炸開，碎片全亮成橘色，兩人穿過井底那座光的湖——湖面就是真實的聊天畫面，她的回覆剛進來。

寓意對照（只有這幾個）：
- 冰 ＝ 聊天冷掉、怕說錯話而僵住。
- 熄掉的螢幕 ＝ 一句沒回的話；堆到把人埋起來 ＝ 沉默。**我們的炎魔沒有臉。**
- 火 ＝ 品牌橘 ＝ 她期待你的回覆。火碰到螢幕，螢幕就亮。
- 他自己動手指 ＝ 教練陪你，訊息你自己送。
- 光的湖 ＝ 真實 App ＝ 出口。
- 天秤／胸架／Key／封印書：不進影片。

倒數計時的尺規：**冰爬到哪裡＋繭長到多大。** 指尖 → 手腕 → 手肘 → 肩 → 胸口；繭從肩寬長到比人大三倍。

## 2. 60 秒節奏表

格式：`START → CAMERA → ONE ACTION → END → CUT MATCH → AUDIO`
單元 U = 一組生成或一段真實素材。**生成策略改為：每支生 5 秒，剪成 1–2 秒的鏡頭用；中段平均 1.2 秒一切。** 接縫一律落在 wipe（蒸氣／白霧／臉糊滿畫面）或同一重力方向的同一移動物。

### U1｜0–7s｜網站就是第一鏡（跳框）
- START：真實網站 hero 畫面靜止，與訪客剛看到的網頁一模一樣。
- CAMERA：緩慢推進右側傾斜手機；推到手機占滿畫面時切成真實 App 首頁截圖。
- ONE ACTION：手機玻璃邊緣起霜往中心爬；橘色入口鈕是唯一沒結霜的地方。最後 1 秒：一隻手指抓在玻璃邊緣，滑掉（LOTR 0:05 手從橋緣滑掉的同構圖）。
- END：手指離開畫面上緣，畫面整片起霜的玻璃，只剩橘鈕發光。
- CUT MATCH：橘鈕 → U2 首幀極遠景底部的橘點。
- AUDIO：房間靜音 → 玻璃結霜脆響 → 指甲刮過玻璃 → 一聲低頻「拉走」。
- 註：0–4s 真實錄屏＋後期推鏡；4–7s 生成（B1 合成＋手指滑掉一鏡）。

### U2｜7–18s｜多深＋倒數開始
- START：**極遠景鎖死 3 秒**（LOTR 0:08 那顆）：螢幕井全高在畫面裡，男主是一個小點往下，井底一粒橘點。先證明「多深」。
- CAMERA：極遠景 3 秒 → 切第一人稱垂直俯衝（近牆高速上刷）→ 切一次側面中景（他在黑暗裡翻滾，只有下方橘光打邊）→ 回第一人稱。
- ONE ACTION：**冰從指尖爬到手腕再到手肘**；同時**井壁的黑螢幕一片片剝下來貼到他背上、肩上**——繭開始長。橘點沒有變大。
- END：第一人稱，雙手手肘以下全白，肩後已有幾片黑螢幕貼著，橘點仍在遠處。
- CUT MATCH：橘點 → U3 首幀從下方衝上來的火。
- AUDIO：風壓、衣物拍打、冰在皮膚上「嗒嗒」延伸的高頻、玻璃片「喀」貼上的聲音；沒有音樂。
- 註：15 秒循環從第一人稱區間剪。

### U3｜18–26s｜火從下面上來＝Sydney 進場
- START：第一人稱往下看，橘點突然放大、變成一團火衝上來（LOTR 0:18 炎魔升起的同一鏡頭語法，但衝上來的是她）。
- CAMERA：第一人稱 → 切她的側面：**她從井底往上蹬牆**，腳踩到哪片熄掉的螢幕、那片就亮起橘光，身後留下一條逐格點亮的軌跡 → 兩人相遇一格（她往上、他往下，速度相抵）→ 接觸切極近景（手對手）。
- ONE ACTION：她抓住他結冰的手臂；**火碰冰，蒸氣炸開**；兩人一起往下。
- END：**男主結霜的臉被拉成模糊填滿畫面（臉 wipe，LOTR 0:20.5）。**
- CUT MATCH：臉 wipe 白霧 → U4 首幀白霧散開。
- AUDIO：火衝上來的低頻轟 → 接觸瞬間的撞擊＋蒸氣噴發 → 風壓變悶。
- 註：這是身份混合最高風險段；接觸只用「手對手極近景」，不讓模型在遠景自己發明抓握。她往上蹬牆的鏡頭裡不出現男主。

### U4｜26–42s｜冰繭搏鬥
- START：白霧散開，兩人抱團翻滾；繭已經肩寬以上，表面是貼滿的黑螢幕＋霜。
- CAMERA（依 LOTR 0:22–1:01 的順序，每鏡 1–2 秒）：
  1. 翻滾遠景，橘白各半。
  2. 蒸氣 wipe → 她貼在繭上 → 他僵直的手臂（近）。
  3. **英雄鏡頭 2 秒（LOTR 0:28）**：她單手撐在繭上、另一手火舉高，正面；從她掌心貼著的那片螢幕開始，繭上的黑螢幕一片片被點亮，橘光像漣漪擴出去；碎冰在她兩側向上飛，框住她。
  4. 翻滾遠景／他的臉（冰裂）／火掌按在冰上蒸氣炸開。
  5. **從上往下看螢幕井，橘白小點退遠（2–3 秒，ENV0 V1 構圖）。**
  6. 近景：繭還在長，牆上的螢幕繼續飛過來貼上去；她的火明顯變小。
  7. **她的臉橫掃糊掉（臉 wipe，LOTR 0:42.5）。**
  8. **再一次從上往下看井，小點更小（2 秒）。**
  9. 極近景：她的火只剩一點，貼在繭上快要熄掉。
  10. **極近景：繭裡面，他的手指動了一下，主動伸出去碰她的手。**
  11. 裂紋從繭裡面炸開（不是從外面打破）。白閃。
- ONE ACTION：**冰在贏 → 他自己動了。**
- END：白閃。
- CUT MATCH：白閃 → U5 首幀極遠景（LOTR 1:01.5 白閃 → 1:02 極遠景）。
- AUDIO：搏鬥段風壓＋玻璃貼上的喀喀聲越來越密；火變小時聲音變薄；手指動的那一格全部靜音只剩一聲冰裂；白閃無聲。
- 註：鏡頭 9–10 是全片唯一「主角做決定」，也是產品真相。不可省。

### U5｜42–50s｜極遠景證明 → 火贏
- START：**極遠景鎖死 4 秒**：井道頂到底全在畫面裡，兩人是一個小點，一半白一半橘，**井底有一片微亮的螢幕面（湖）**在等。
- CAMERA：固定 4 秒 → 急推進到近景。
- ONE ACTION：小點裡的橘光突然放大，**繭整個碎開，碎片就是那些螢幕——每一片飛上去的時候都亮成橘色**；融水跟蒸氣一起向上；兩人下墜速度肉眼可見地慢下來。
- END：兩人幾乎懸停，他手指能動，她的火只剩一點但還在；他們對看一眼；腳下是那片光的湖越來越近。
- CUT MATCH：對看 → U6 首幀兩人穿過湖面。
- AUDIO：極遠景只剩低頻和極輕的風；繭碎是全片最大的一聲；之後突然安靜。

### U6｜50–60s｜穿過光的湖＝回到真實 App
- START：兩人往湖面落下；湖面是一整片亮著的螢幕。
- CAMERA：跟著兩人穿過湖面（生成 2 秒，水花是橘光不是水）→ **穿出來就是真實 App 聊天畫面錄屏**（男主稍早送出的那句還停在那裡）→ 靜止 → 最後拉出成為網站 hero 的手機框。
- ONE ACTION：**她的回覆進來**（真實 App 通知／訊息氣泡，錄屏）。
- END：回到網站 hero 構圖，標語「配對成功只是開始／讓她期待你的回覆」，App Store 鈕。
- CUT MATCH：頭尾都是網站 hero。
- AUDIO：穿過湖面一聲悶的「噗」→ 一聲真實 iOS 訊息提示音 → 品牌收尾音。
- 註：穿湖面 2 秒生成；之後全部真實錄屏，不得自創訊息內容或假 UI。穿湖面→錄屏的接點是後製難度最高的一刀，Eric 已接受。

## 6. 從 LOTR 偷的五條語法（送件時逐條核）

1. 長—碎—長：兩段極遠景鎖死（U2 開頭 3 秒、U5 開頭 4 秒），中間平均 1.2 秒一切。
2. 每次換尺度用「東西糊滿畫面」接：蒸氣、白霧、**臉 wipe**（U3 尾、U4 鏡 7）。接縫處不需要身份一致。
3. 鏡頭跟著翻滾轉、沒有地平線；唯一方向參考是光源，火永遠在下方。
4. 接觸從不在遠景解釋：手對手、手指動、火掌按冰，全部極近景；遠景裡兩人只是一團橘白。
5. 「從上往下看井、小點退遠」出現兩次（U4 鏡 5、鏡 8），觀眾自己算出掉了多遠。
