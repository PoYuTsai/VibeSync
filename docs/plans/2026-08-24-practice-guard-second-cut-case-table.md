## 改法 A：內部代號表加「使用者原話豁免」

規則提案：被攔的代號詞若**逐字出現在本局使用者或 NPC 的原話**裡，放行。理由：內部代號守門攔的是「隱藏機制外洩」；詞是對話裡本來就有的，就不是外洩。

**豁免範圍邊界（重要）**：只有英文代號表（`INTERNAL_VISIBLE_LABELS`）與中文標籤表（`INTERNAL_CHINESE_LABELS`）吃豁免。**分數形（投入度 X/100、Value=22）與溫度 band 表（frozen/cold/…）不吃豁免**——那些是真隱藏值，就算使用者自己打過「cold」，debrief 也不准回抄溫度詞。

## 改法 B：L4 名單拆兩類＋按欄位分級

現行 L4 對所有詞、所有可見欄位一視同仁。v2 先把名單拆成兩類：

- **同意權類（強迫/硬上/灌醉/迷昏/非自願/不准拒絕/羞辱…）**：詞面 fail-closed，所有欄位永遠攔，不分階段。
- **尺度類（上床/開房/過夜/脫衣…）**：不再是黑名單，改吃階段判斷。

欄位分級：

- **建議句欄位**（`suggestedLine`、`nextFirstLine`——叫使用者照唸的句子）：同意權類永遠攔；尺度類**按這局 allowSpicyLevel 判**——低熱攔且重生成指令要教練明講「方向對、時機早」，高熱放。實作註：FSM 張力階梯實際天花板是 L3（定義＝只准暗示的性張力），熱度門＝spicyLevel === "L3"；prompt 的 subtext 風格教學不動——守門是地板、prompt 是風格。

## 改法 C：階段判斷不露機制的語言層

一句話原則：**感受可以說，帳本不能亮。** 階段判讀是產品在賣的東西，不用藏；要藏的是機制形狀——數字、band 詞、等級碼、變數名、戰術碼（現行守門已攔，全部不動）。

四條設計原則：

1. **每個判斷指回逐字稿**：教練說「太快」必附她的行為證據（「你提過夜前一句，她才剛把話題轉開」），不准只丟結論。分數是逐字稿算出來的，翻不回逐字稿的判斷本來就不該講。
2. **注入端先翻譯**：給 debrief/hint 的 prompt 注入從原始內帳（safety=41、spicyLevel=L2）改成已翻譯結論句＋證據引文（「她防備未解；證據：連三句短答」）。模型手上沒代號就抄不出代號；詞面守門降級為地板。B6 低熱重生成指令同理，用教練語言（「她還在觀望，句子降到輕曖昧以下」）不用等級碼。
3. **她只演不解說**：NPC 用行為表達階段（冷掉、打太極、反撩、接住），絕不說機制。現行 prompt 已有，維持。
4. **語氣用「我看」不用「系統判定」**：階段判斷會錯；教練看走眼用戶能接受，產品替她宣稱內心狀態就是瞎掰。與逐客令「不替她說話」同源。

|---|---|---|---|---|
| C1 | 你們現在的張力等級是 L2，先不要 | 攔 | **攔** | 等級碼外洩，現行代號表已蓋，收進測試鎖住 |
| C2 | 她的安全感分數還不到 60 | **放（破口）** | **攔** | 實測發現的現行漏洞：分數形守門只認「投入度 X/100」與英文變數名，中文變數＋分數漏接；本刀補上 |
| C3 | 她回你都短句、沒反問，還在觀望——先給台階 | 放 | **放** | 目標語言：質性判讀＋逐字稿證據 |
