### 章 1：限制性信念

**核心機制——大腦替錯誤信念找藉口的三段退守**：拿真實影片給人看，他會依序退守
「那是找演員演的」→（證明不是）「那是因為你長得帥」→（給他看不修邊幅也成功的）
「那是因為你那個城市比較開放」。面對無法解釋的事實，人寧可相信自己臨時編出來、
彼此矛盾的藉口——因為承認事實等於承認自己可以改變卻沒改變。
→ 適合做 `dialogue` 或三段 `comparison`。

**六條最常見的限制性信念**：
1. 我不帥所以女生不喜歡我（把長相當唯一變數）
2. 漂亮女生本來就該跟有錢人在一起（先幫對方做完決定）
3. 那麼快發生關係的女生比較隨便（用道德判斷迴避能力問題）
4. 我相信緣分，現在單身是緣分沒到（把被動包裝成信仰）
5. 我不需要有魅力，反正要找老實結婚的（放棄成長的藉口）
6. 年輕該拚事業，有錢自然有女人（反例：收入很高卻長期單身）

**共同結構**：每一條都把「我沒有行動」翻譯成「我不需要行動／行動也沒用」。
→ `checklist` 六條逐條勾「這條我有沒有」。

### 章 2：需求感（立場最鮮明，建議當樣板章）

**反主流主張**：市面上都說「不能暴露需求感」，這是錯的且有害。需求感是本能，
消不掉，你按下傳送鍵那刻它就在了。照著「完全不表達喜歡」做的人結果是**依然
得不到**，然後被歸咎到別的問題上。要控制的不是慾望，是**慾望有沒有奪走判斷力**。

**五種被需求感綁架的聊天行為**（★ 對聊天 App 直接可用，做 `entryList`）：

| 內在 | 在對話裡長什麼樣 |
|---|---|
| 貪 | 一天連發好幾則、她沒回又補一則、訊息越來越長 |
| 瞋 | 她慢回就冷處理／陰陽怪氣「看來你很忙」 |
| 癡 | 她說在忙還繼續發、把已讀當拒絕 |
| 慢 | 硬塞車錶餐廳出國照，把展示面當籌碼 |
| 疑 | 反覆問「你是不是不想理我」「我是不是很煩」 |

**判準**（做 `callout(principle)`）：說完之後，主導權還在不在你手上？
- ✅「我蠻想見你的，你這週有空再說」——表達了慾望，沒交出主導權
- ❌「你到底想不想見我」——把慾望變成對方要處理的情緒

### 章 4：情人與供養者（材料最厚，30KB）

**先破誤區**：把對象分類（拜金女／綠茶婊／好女人／我的真命天女不一樣）會讓你把
結果歸因到「對方是什麼人」，而不是「你們之間發生了什麼互動」。分類讓你停止學習。

**兩種擇偶策略**：供養者路線以生存資源為優先，先讓對方大量投資才推進；情人路線
以特質為優先，從眾多對象裡挑一個。

**被放在供養者位置的八個訊號**：肢體始終高度抗拒／關係推進被無限延長／坦然收下
付出且引導你投資更多／時間地點內容都由她安排／出現不合理要求／追很久發現是備選／
你始終被動／交往後莫名被劈腿。

**為什麼「對她好」會失效（機制，不是抱怨）**：社會、父母、朋友教的追求法——多關心、
送禮物、請客——**就是供養者策略本身**。用它等於跟她身邊所有供養者比拚物質，而規則
是出價最高者得，**結構上不可能贏**；就算暫時贏了，她選的是資源不是你。
這叫**邏輯選擇，不是吸引**。

**對聊天 App 的翻譯**（產品最需要的部分）：供養者行為在還沒見面時就看得出來——
秒回而她慢回你焦慮／有求必應／情緒勞動全你承擔／用資源開場而不是用互動／
一直問她要什麼卻從沒說過自己要什麼。

### 章 3：一致性（材料比原本預期好很多，建議升為第 1 冊第二根樑）

原訂標題「裝出來的價值撐不過見面」只涵蓋了一半。真正的主軸是**一致性**：
前後對得上。裝出來的價值只是它最明顯的一種違反。

**核心比喻——展示面就是履歷**：履歷寫得漂亮換到面試機會，真人一開口對不上號，
還是被刷掉。就算主考官不懂你的專業、讓你混進去了，一旦真的要解決工作上的問題，
你依然會被發現不是他要的人。
→ 這是全單元目前找到最好的一個比喻，`comparison` 或 `callout(principle)`。

**一致性斷裂的具體代價（不是抽象的）**：月入五千包裝成五萬，吸引來的對象最後
是自己承受——約會帶人家吃路邊攤，前後對不上；硬撐去高檔餐廳，看到菜單一頭冷汗，
兩三個月薪水不夠吃兩三頓。花掉的時間精力竹籃打水。

**反直覺的那一段（適合做 `dialogue`）**：學員最怕被問「你是不是搭訕過很多女生」
「你是不是在學這個」。作者的答案是照實說。怕被知道，傳遞出去的潛台詞是
「我不願意為自己的行為負責」——而那正好是最沒有吸引力的特質。廢物測試測的
從來不是你答得漂不漂亮，是你有沒有一致性。
**對 App 的翻譯**：被問到敏感問題時，慌張改口、急著否認、換個說法圓過去，
都比誠實回答傷得更重。

**「你喜歡的人不喜歡你」的解釋**：多數人在不喜歡的人面前輕鬆做自己（＝一致），
在喜歡的人面前反而拘謹（＝不一致）。所以在不在意的人面前反而有吸引力。
→ 這條非常適合開場，因為每個人都親身驗證過。

**一致性怎麼練（重要，避免被誤讀成「做自己就好」）**：先刻意去做你目前**不一致**
的事，做久了它變成一致，這時候才輪到「真實性」生效。順序不能倒過來——
真實性不是把宅在家打遊戲吃泡麵那一面攤出來就叫真實，那不會有吸引力。

**四個誤區（來自高階技術 學前引導，每一條都能單獨成 block）**：

| 誤區 | 為什麼失效 |
|---|---|
| 靠展示面堆高價值 | 見面被打回原型；且把「展示價值」內化後會變成供養者 |
| 靠怪異／攻擊性行為製造吸引 | 能承受社交壓力確實有吸引力，但把奇葩當策略只會被邊緣化 |
| 問對方「你喜歡什麼樣的人」 | 她回答時心裡想的是一個她自己配不上的人，「對我好」是希望**那個人**對她好 |
| 依賴固定套路與話術 | 不成系統、對高分對象會被看穿，而且一有能用的方法就停止探索 |

其中第二條的正解值得單獨拉出來做 `comparison`：對方說了你不同意的話，
① 一路附和「你說得真好」＝追逐她的價值；② 指著鼻子嘲笑打壓＝糟糕的社交體驗；
③ **「我覺得你說的也沒錯，不過我是這樣想的」＝微調，同時把自己的框架植進去**。

**自娛自樂的正確定位（細膩且反直覺）**：它**不產生吸引力**，它只是讓你不那麼消極、
不那麼有需求感、不那麼有目的性。沒有自娛自樂一樣可以吸引人。別把它當吸引力來源。

### 章 5：價值、能量、屬性

**吸引力結構樹（可做 `stageFunnel` 或 `entryList`）**：
```
外在價值 ─┬ 生存價值
          └ 繁殖價值（身材、身高、外貌、健康）
吸引力  ─┬ 心動指數 ─┬ 價值（內在／外在）
          │            └ 能量
          └ 心疼指數（暴露敏感面）
```
繁殖價值**直達荷爾蒙系統**，不經過邏輯思維系統——看到就有反應，不需要先想。
這解釋了為什麼照片這一關無法靠聊天補救，也解釋了為什麼它補救不了後面所有的關。

**能量三來源**：先天生命能量、身體狀態、情緒。
**排除**：原始材料把先天那一段講成生辰八字與胎教。不可證偽且離定位太遠，整段不寫。
**保留**：意識干不過潛意識（知道該戒菸卻戒不掉）。→ 直接對應「你明明知道不該連發
三則訊息，但你還是發了」。這是整個單元存在的理由，適合放在第 1 冊開頭。

**屬性**：同一個人身上會被讀出不同屬性（可以交往／可以結婚／短期）。第一印象在
幾秒內完成，而且經常判斷錯——穿得開放的可能很保守。屬性最快的調整手段是穿著打扮，
但**必須跟行為與氣場匹配**。

**高能量低價值（章 5 最該落地到 App 的一條）**：穿著／頭像／簡介的能量很高，
把注意力吸過來了，一互動發現接不住、不會聊、沒有立場——比一開始就低調更糟。
因為你把人叫過來看的是一個低價值的樣本。
→ `callout(warning)`：**展示面的能量不要超過你接得住的程度。**

**TOP 原則**：Time／Object／Place。重要場合穿重要的衣服。
（AB 款西服、衝鋒衣那些具體穿搭建議與 App 距離太遠，壓成一句帶過即可。）

### 章 6：她要的是哪幾種感覺（材料最好的一章，兩集都可用）

**六種感覺的層級（`stageFunnel` 的完美素材）**：
安全感 → 熟悉感 → 舒適感 → 親密感 →（進入關係後）依賴感 → 歸屬感。
每個階段六種都需要，只是比例不同。**安全感是地基，一旦抽掉上面全塌。**
熟悉感靠共同的圈子、話題、關心；異地就是熟悉感的考試——熟悉感掉了，舒適感跟著掉，
誤會累積、情緒沒有出口，分手只是時間問題。
依賴感／歸屬感的建立方式：**把對方的規劃放進你自己的人生規劃裡**。

**7／38／55 定律（建議放在第 1 冊最前面，它就是整個內功線的存在理由）**：
一個人給出的印象由三部分構成——
- **7 分＝聊什麼**（文字內容）
- **38 分＝怎麼聊**（語氣、語調、語速）
- **55 分＝誰在聊**（眼神、穿著、表情、氣場、舉止）

所有人都在問「這句話怎麼回」，那是 7 分那一塊，拿滿也只有 7 分。
→ **這條要誠實地寫**：VibeSync 幫你的正是 7 分那一塊，而這個單元要補的是 55。
把這件事講明白，比假裝回話技巧能解決一切更有說服力，也正好交代了新單元為何存在。

**什麼是「撩」——兩個基本特徵（★ 對聊天 App 最直接可用，做 `comparison`）**：

| | 撩 | 對 |
|---|---|---|
| 幅度 | 小。一點一點地試探，進兩步退一步，螺旋前進 | 大。「你到底喜不喜歡我，行就行不行拉倒」 |
| 心態 | 挑動完之後，不管對方反應好壞，情緒與心態不受影響 | 對方反應不如預期就崩，只能打順風局 |

第二條的判準寫法：**你說完那句話之後，需不需要她的回應來決定你的心情？**
只能打順風局的人，逆商低＝心力成熟度低，這件事會被看出來。

**三種特質（`checklist`）**：勇敢、心思細膩、臉皮厚，缺一都出問題。
- 勇敢＝敢發起，但**前提是已經有吸引**，不是沒有吸引硬上（這句要照寫，是紅線措辭）
- 心思細膩＝聊天時不要一心想著自己接下來要說什麼、什麼時候可以升級，
  要真的聽她表達了什麼
- 臉皮厚＝推進的責任在你，不要等對方主動
- 一句話收束：**做流氓般的紳士，不要做紳士般的流氓。**

**主動權——小男孩牽手（★ 全套材料裡最好的一個意象，做 `dialogue`）**：
小男孩去牽小女孩的手，在她甩開**之前**先鬆手。她那一下甩在空氣裡，沒有著力點。
主動權留在他手上。
→ 對照組：聊到晚上她沒回，你補一句「你睡了嗎」，再補一句「你還在嗎」。
主動權就這樣交出去了。
**延伸的主導權意識**：你只懂得主動開啟，從來不懂得在該結束的時候主動結束對話。
那主導權跑到對方手上是理所當然的。

**雞蛋原理（`comparison` 三層）**：蛋殼＝社交面具（破冰期要破的就是這層）／
蛋白＝人性中溫柔善良的一面／蛋黃＝人性中慾望與陰暗的一面。
- 只看到蛋白 → 神化對方；只看到蛋黃 → 全盤負評。兩者都是以偏概全。
- **關鍵且正好對沖掉原始材料的怨懟**：蛋黃不是誰特有的，是人都有，包括你自己。
  這一句一定要寫進去，它是整章的道德錨。
- 破殼能力差＝進不去。這正好接上章 7 的自在感——**你自己沒放鬆，對方不會卸下面具**。

**情緒題不要用邏輯答（★ 最好的 `dialogue` 素材）**：
經典的「我跟你媽掉水裡先救誰」。影片裡的男生一路用邏輯解——找救生圈、找會游泳的
朋友、找力氣更大的朋友——結果是無限循環，永遠答不完，而且越答越輸。
最關鍵的一次翻轉機會是她說「我這麼胖，你朋友抱不起我」，他回「那我找個力氣更大的」。
走情緒的答案是「你哪裡胖，我覺得你剛剛好」——話題當場就轉了。
→ 抽象成可用的判準：**她問的是感覺題，你在答申論題。**
先辨認這是哪一種題目，再決定要不要動用邏輯。

**方向盤（`callout(principle)`）**：她跟你搶方向盤，要的不是方向盤，
是搶的過程裡產生的互動感。你真把方向盤讓出去，車會開翻，她走了你又不接受。

**本章必須改寫的三處**（原始材料踩規範 4）：
1. 「女人天生情緒化」「生理期影響情緒」＝刻板印象。可保留的結構洞察是
   **人在情緒狀態下提出的問題不是資訊需求，是情緒需求**——不分性別，而且更準確。
2. 「女人有時候需要善意的謊言」→ 改寫成：她要的是「我在你心裡有位置」的確認，
   不是一份可執行計畫。給確認不等於說謊。
3. 「你實際上是不是把她放第一位反倒不重要」→ 整句刪除，這是教人敷衍。

### 章 7：極性（原名「雄性極性」不能用，建議改名）

**先講結論：這四個檔是全單元政治風險最高的材料，內核篇 07 幾乎整篇排除。**

排除清單（規範 4／5，不可放寬）：
- 內核篇 02 用強姦幻想的問卷數據當作「雄性極性」的立論起點，以及「征服＝
  由上而下的統治」整套推導 → **整段排除**
- 內核篇 07 的「你不上她不代表別人不會上她」「征服她、侵略她、占領她」
  「未經同意侵入她的私人空間」 → **Guideline 1.1 正中紅心，整篇排除**
- 去雌化／白左／中情局改造日本、點名真實藝人是「娘炮」、體型評價 → 全部排除
- 「不要打飛機以保留睪固酮」 → 排除
- 「永遠不要回答她愛不愛我」「心理距離永遠要比現實距離遠」 → 排除。
  這是把「早期不要一次掀底牌」錯誤外推成終身策略，在長期關係裡是有害的

**排除之後真正剩下的東西**（仍然足夠撐一章，而且比原本乾淨）：
極性是個磁鐵比喻——同一組特質有正負兩端，你**站在哪一端**決定了吸引還是排斥。
三組對立軸，每一組都能單獨落地：

| 負極 | 正極 | 對聊天 App 的翻譯 |
|---|---|---|
| 約束感 | 自在感 | 你打完那句話之前，先想的是「這樣說她會怎麼看我」還是「我想說什麼」 |
| 坦誠感 | 神秘感 | 第一週就把工作、收入、感情史、你有多喜歡她全部交代完 |
| 屈從感 | **立場感**（原名侵略感，必須改） | 「都可以」「還好吧」「你決定就好」 |

**約束感的定義要精準**：它是**你自己給自己的**條條框框，不是別人給的。
典型症狀：「明天要上班，所以今天不方便」——理由永遠成立，而且永遠是你自己提的。
來源有二：照著社會規範走，以及一直照別人替你規劃好的框架行動，
**從來沒有自己驗證過現實**。
**誠實的一段**：在工作與群體裡，約束感不是壞事，它保證協調性。問題是把整套原封不動
帶進兩性互動。這句一定要寫，否則整章會變成鼓吹不守規矩。

**自在感的定義**：說一句話之前，不會先過一遍「社會會怎麼評價我」。
它的來源不是膽子大，是**你有一套自己驗證過的價值系統**。
→ 效果那一段接得上章 6 的蛋殼：**你自己戴著面具，對方不會卸下她的。**
自在感就是破殼能力的內在版本。

**神秘感可保留的部分**：
- 老虎捕獵：不會憑優勢直接撲上去，先做試探性的假動作、目光游移、等對方先動。
  ＝試探與預判。
- 猶抱琵琶半遮面：遮住一部分才有想像空間。
- 熟人圈難吸引，因為社交價值早就被錨定了。→ 這條中性且好用。
- 你變成透明人 → 她覺得你已經吃定了 → 她不需要再為這段關係做任何努力 → 張力消失。
- 老闆／員工類比：決策者沒必要把每個決策背後的理由都解釋給下面聽。
- **「傲慢才是殺死人的武器」**：弱小可以靠努力補，無知可以靠學習補，
  但認定「這種事不需要學、對方很好懂」的傲慢補不了。
  → **建議放在第 1 冊的最後一章收尾，或第 1 章開場。**

**立場感（改寫後的正極）**：
交流裡要有明確的喜歡與討厭，不要什麼都「還好吧」「都可以」。
中性＝沒有資訊＝沒有吸引力，而且會讓對方無從接話。
→ 這是原始材料裡唯一乾淨、且對聊天 App 極度可用的一條，值得整章壓在它上面。
初期刻意練習會覺得怪，這很正常，練到後來會跟一致性合流（呼應章 3）。

**三章共用的收尾**：三集結尾都講了同一句話——只聽課不實踐，
你很快會被拉回原來的狀態。這句適合當第 1 冊的最後一段。

## 寫作規範（非常重要，接手不要放寬）

1. **一句原文都不能引用。** 來源是語音逐字稿，錯字極密：皮配率＝匹配率、
   EARO Scores＝Elo Score、自于自乐＝自娛自樂、况下＝框架、搭扇＝搭訕、
   共扬者＝供養者、一支性＝一致性、米南／迷難＝迷男。全部理解後重寫。
   第二輪讀出來的新錯字：意志性＝一致性、費物測試＝廢物測試、核盟系統＝荷爾蒙系統、
   自舞＝自我、熊姓／雄心理性＝雄性、二法＝alpha、屬性感＝**熟悉感**（章 6 的六種
   感覺之一，同一集裡兩個詞混用，靠上下文判斷）、高童素＝睪固酮、悲塌男＝Beta 男、
   課值＝客觀、募強／目強＝慕強、責偶／折偶＝擇偶、50到＝武士道、珍石性＝真實性。
   **`屬性感` 這個坑要特別小心**：魅力原理第八集裡「屬性」與「熟悉感」被念成同音，
   照抄會把整個六層模型寫錯。
2. **拿掉所有素材出處的名字**（Bruce 要求）。`sourceRefs` 是 JSON metadata，
   grep 過整個 presentation 層**從來不渲染給使用者**，所以天然成立，只要保持
   欄位合法即可。
3. **不寫考試型內容**（Bruce 要求）。`quiz` block 目前用量為 0，維持。
   但 `flipCard`（先問後翻）、`dialogue`（逐句拆）、`comparison`（好壞對照）、
   `checklist` 不是考試，正好補互動感——終極指引 20 章 134 個 block 裡
   paragraph 佔 70 個，互動性其實不成立，新單元不要重蹈。
4. **不寫怨懟**。原始材料在關係篇帶明顯情緒（劈腿故事、名人例子、對女性的評價）。
   排除的理由不是道德，是**怨懟會讓讀者變差**：帶著「女人很現實」的框架去聊天，
   只會更防衛、更計較、更不吸引人，剛好違背這本書要做的事。保留結構洞察即可。
5. **App Review 紅線**：寫「怎麼判讀訊號、怎麼建立框架、怎麼推進」可以；
   寫「怎麼繞過對方明確拒絕」不行。這是 Guideline 1.1，是整個 App 下架等級的
   風險，不是改一篇文章的等級。原始材料有幾篇踩線（例如紅丸會員那篇談 MeToo 的），
   整篇排除。
6. **半形逗號**：終極指引現有內容把逗號寫成半形 `,`，是排版瑕疵。新單元用全形，
   順手的話也可以修舊的（另案）。

## 重建工作環境

```bash
# clone 課程 repo（scratchpad 是 session 專屬，換 session 要重來）
git clone --depth 1 -b claude/organize-courses-by-name-kh4z3h \
  https://github.com/chiang53610-droid/chris.git chris-courses

# 產生 256 檔的主題摘要（避免整份讀）
python3 - <<'PY'
import os,re
root='chris-courses'; lines=[]; cur=None
for dirpath,dirs,files in sorted(os.walk(root)):
    if '.git' in dirpath: continue
    for fn in sorted(files):
        if not fn.endswith('.md') or fn=='SUMMARY.md': continue
        d=os.path.relpath(dirpath,root)
        if d!=cur: cur=d; lines.append(f"\n### {d}")
        txt=open(os.path.join(dirpath,fn),encoding='utf-8',errors='replace').read()
        body=re.sub(r'\s+','',re.sub(r'^#.*\n','',txt).strip())
        lines.append(f"- {fn[:-3]} [{len(txt)//1000}k] :: {body[:110]}")
open('digest.txt','w',encoding='utf-8').write('\n'.join(lines))
PY
```
