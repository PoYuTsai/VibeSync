## 全篇研究：01 肯定感練習（12:18.836；739 幀）

證據：practice-01-ocr.jsonl、practice-01-ocr.md。原檔 460654900 bytes 與 Drive metadata 一致。

- 00:34–01:40：學員自述搭訕少、緊張。實例從眼鏡的個性、是否結婚、衣著等切入；一人直接說不加微信，一人說已婚育兒後學員道別。不能把所有拒絕都說成技巧不足。
- 01:44–02:43：教練診斷不是缺一句神奇台詞，而是對方短暫看一眼又回到原本要做的事。稱第一步是取得注意，再談確定／確信感。
- 02:44–04:02：兩種內在卡點：覺得自己的接近很奇怪／像打擾；或者自己不知道上去要做甚麼、叫停後腦袋空白。教材將此與外顯猶豫連結。
- 04:06–04:40：以交警、查證人員來意很明確為類比；這是教材的權威角色比喻，不是搭訕可以擁有相同權限。
- 04:41–06:44：實際練習是讓學員在地鐵口假稱施工，請路人改道。路人包含照走、繞過、問原因等反應。
- 06:49–08:20：教練評估學員不夠相信自己做的事，用危險入口的假想例子解釋信念影響表達。
- 08:22–09:29：第二輪未更好；09:10附近教練明說學員知道事情是假的，所以不確信。不是「多做一次一定進步」。
- 09:30–11:24：重點回到潛在溝通；教練認為還沒說完目的，對方已從行為感到你有話要講。教材把路人不相信歸因確信感，這只是講者的解讀，沒有排除他們知道實際入口正常等原因。
- 11:26–12:00：第三輪入口改道練習，片尾未提供長期追蹤。

產品可取：讓玩家先承認自己真實的認識意願，句子與姿態一致；取得注意後才展開。不可照搬：假警告施工、冒充管理權限、以攔路當作分數更高的動作。Sydney 應教清楚表達與穩定，而非讓女生服從。

## 全篇研究：03 流動感練習（836 幀，全片跨度）

證據：practice-03-ocr.jsonl、practice-03-reading.txt。原檔 325539625 bytes 與 Drive 一致。

- 00:15–01:24：學員把背過的句子說成習慣；對方仍在停留聊天，自己卻因不知下一句而匆忙結束。教練所稱對方明顯不想走，是他的觀察解讀，非讀心事實。
- 01:26–02:49：流動感定義為自然自在，好像和朋友交流，不一直在腦內檢查下一句該說甚麼。
- 03:01–03:58：初學者可能緊張當機；中段學員可說固定句，但要從固定句發散到當下實際觀察。不是永遠禁止任何句型支架。
- 04:04–04:25、05:53–05:59：教材用左右腦切換解釋固定／發散思維。此處不能直接當科學機制寫進產品；可使用「從背稿改為注意當下」的行為描述。
- 04:56–07:50：三點練習：不要把短暫沉默當災難；用「我覺得、我想、然後」作過渡讓思緒繼續；不要因擔心顯傻把每個想法都否決。教材甚至說不用在意反應、評論褲子奇怪；產品需保留觀察與接話，去掉刻意冒犯與忽略反應。
- 08:23–08:50：稱讚笑容、藍衣，問婚姻，對方已婚後結束。
- 08:59–10:04：對方不想被叫姐、不想當老婆，剛分手且無意找伴侶。學員接著用適婚年齡／三十走下坡說法，這是壓力與年齡貶低，不能設為正解。可用作回放中「你沒有接住她說自己剛分手」的反例。
- 10:20–10:58：教練肯定發散內容改善，但指出仍跟著對方走。稱較好的連接是眼神注意而非單純攔人。
- 10:59–11:39：分辨邊慢走邊轉頭回答的情況；提出移到側前方、自己慢慢停。可萃取減少對方扭頭負擔與保持可見，而非擋住去路。
- 11:40–12:51：教材對走很急者提出肢體截停、更強確定感；產品不可照搬成必須阻止離開。趕路者應有離開權，替代為一句清楚招呼後看是否願意停。
- 12:52–13:38：保持側面或稍前位置，避免一直在後方令對方扭頭吃力。原片未提供公分級距離或可據以制定拍肩精準位置的尺寸。

## 從七片整合到夜市 MVP 的設計提取（研究者建議，非原課逐字）

1. 先有自己與 Sydney 的生活感：看攤、閒聊、看到具體細節，玩家有自己的好奇與選擇。不要見到女生立刻跳題。
2. 接近前只給一個短提醒：「先吐口氣。你是想認識她，不是去表演。從她看得到的地方說嗨。」三秒作可選練習節拍，不能扣成超時失敗。
3. 取得注意与介紹來意分開：她可能轉頭、沒聽見、手上正忙；玩家先辨認，再說自己的現場背景與真實觀察。拍肩不是必需動作，且這七片没有足以制定拍肩位置的精確教學證據。
4. 安全感来自可以理解與可以離開：簡短說為何接近、保持空間、不把身體擋在路上；不是重複自證不是壞人。
5. 流動對話用「她上一句→我的真實回應→小段自我分享或好奇」；不能只有問卷選項，也不能只發散自說。讓女生主動反問、不同意、修正你、聯想到別的事。
6. 娛樂與張力来自共同的小誤會、觀察、接梗與停頓。沒接好可修復，不用靠貶低、驚嚇或不停升級。
7. 熱度、忙碌、安全疑慮分開判斷：有笑也可忙；有空也可沒興趣；禮貌回答也可想走。眼神、朝向、主動提問都是暫時線索，需要與話語和後續選擇一起看。
8. 即約只在有空且雙方願意下提出具体短活動；忙但想再聊可詢問聯絡意願；不想繼續則友善道別。以是否理解對方與表達自己作回顧，不以收號數判成敗。
9. Sydney 平時旁觀，在玩家卡住、忽略關鍵資訊或回顧時提示；不搶女生話、不替玩家答每句。練習結束用實際一個漏接訊息和一個做得好的動作，接回方法卡，再重試同節點。
