本產品改寫使用現有 Leah profile：`practice_girl_078`，27 歲、新竹職能治療師；標籤為溫暖、專注、有界線，興趣為手作、散步、心理學。夜市素材只採無糖烏龍、下班散步與手作陶杯等已知方向，不替她捏造其他身份或未提供的背景。她的興趣是可被玩家問到的素材，不是固定觸發的浪漫訊號。

本輪拍攝以具體觀察米色外套並說明來意開始。Leah 只在一處提出推銷疑慮；互動核心是下班買茶、男主第一次拉坯的歪杯、Leah 問「那是杯子還是花盆？」、男主接住笑點，接著回應「你很常這樣跟女生打招呼嗎？」。Sydney 在入場與復盤時出鏡，在對話選擇時提供簡短文字提示；她不代替男主回答。

現行 source 的終點以 `available`、`busy`、`date`、`contact`、`decline` 與 text-only `pause_ending` 表示：有空時可做兩分鐘手作攤邀請，忙碌時可一次提出低壓聯絡方式，或尊重離場；拒絕與繼續逛都不代表失敗。玩家不能代替 Leah 選話；選項只改變男主台詞與狀態，Leah 台詞依條件播放；一般影片結局回到 Sydney coach，`keepwalking` 直接文字復盤。

研究材料能支持字幕層的章節與時間定位，不能冒充完整逐字稿。所有時間碼約有 ±2 秒誤差；未完成全片逐秒聽打、全量聲調核驗或全量身體動作標註。原圖核對只確認該幀可見的站位、持物或字幕，不等於完整行為證據。`practice-manifest.json` 明列未做 audio transcription；`opening-source-manifest.json` 明列 allAudioAndBodyMotionReviewed 為 false。原創劇本因此只意譯方法與風險，不抄錄台詞，也不把作者的推測當產品事實。

## 跨片共通的可用方法

第一，開場不是背一句神奇台詞。Opening 01、03 與 Practice 01–02 都把注意、目的與真實觀察放在前段；Opening 11 則把開場、背景、話題、肯定與收尾串成流程。產品實作成「具體觀察 → 說明來意 → 停等」，而非不斷解釋自己。

第二，對話要有來回。Opening 01 的反例是女方問工作，男方仍重複「想認識」；Practice 03–04 反覆提醒由背稿轉向眼前素材；Practice 09 將自我表達放回流程。MVP 讓 Leah 問工作與來意，玩家先答，再分享一小段自己，最後才回問；錄影與獨自來夜市等早期草稿台詞已刪除。

第三，肯定必須能指出根據。Opening 11 與 Practice 02 有從衣著、動作、興趣進入的例子，但外貌與婚姻問題不適合作通用模板。夜市劇本用 Leah 的米色外套作具體觀察，再以她分享的手作興趣接話，避免「妳很特別」這類空話。

第四，流動感不是不停說話。Practice 03–04 顯示自然停頓、陳述、聯想與回應；Practice 04 也有「一直講但沒有注意」的反例。Sydney 只在玩家卡住或漏接明確資訊時提醒一個動作，不在 Leah 說話時長講。

第五，娛樂感來自共同情境。Practice 05、Tests 08 可取共同玩笑與符合個性的回應；突然跳出、嚇人、假裝聽不見和貶低式反擊不能搬進產品。夜市叫號與歪陶杯是低風險、可撤回的原創笑點。

第六，忙碌、參與、疑慮、浪漫好奇要分開。Practice 02/08/09 與 Tests 07/09 都有等朋友、找路、上課或拿茶的時間限制；Advanced 06 明說社交上鉤不等於吸引。這些是劇本寫作判準；目前 MVP 實作有限選項與獨立時間情境，沒有讀心或表情推斷模型，也不以笑、停留、回問或交換聯絡任一訊號推導她的心聲。

第七，環境主導應表現在自己先處理場面。Opening 04、Practice 08/09 提到人流、座位、陪同者與距離；作者的拉、截停、把朋友當障礙等主張與產品界線衝突。夜市取茶片段保留 Leah 回頭拿茶的時間，玩家等待她回來接話；邀請一起走到旁邊攤位需等她答應。

第八，觸碰不是進階關卡。Opening 11 的握手畫面只能證明伸手邀請，不能證明接觸；Advanced 06 的握手尷尬、Advanced 07 的退避與 Practice 05 的驚嚇都支持保留距離。玩家可不碰觸仍完成高品質交流；拍肩、不退開、跟著走都不等於同意。

第九，收尾有多個有效結果。Opening 02、Practice 02/08/09 與 Tests 07–09 都顯示忙、拒絕、交換聯絡和即約是不同結果。VibeSync 回顧看的是是否清楚、互惠、尊重與能處理時間，而非收號數或 Leah 是否「被拿下」。

## 研究主張與產品改寫分離

### 來源中保留為「作者主張」的內容

課程常使用確信感、控制力、男性競爭力、上鉤點、廢物測試、服從升級、女性選擇者等框架，並對笑、忙、離開、給聯絡方式作較強心理解讀。部分片段還有無收音、回憶口述、重複案例與未提供後續追蹤。這些內容可作研究材料的背景，不能在產品中當統計、心理診斷或安全保證。

### VibeSync 產品重寫原則

把「確信」改成目的與行為一致；把「控制」改成自己先讓路、問同意、守時間；把「廢物測試」拆成共享玩笑、真疑慮、拒絕/不適三類；把「上鉤」拆成社交參與、當下有空、浪漫好奇與距離舒適度；把「升級」改成可撤回的邀請，不設碰觸門檻；把「成功」改成清楚表達、互惠、尊重界線和自然結束。

## 產品驗收與回放

- 每支原片都在索引中列出來源、時間碼與限制；不宣稱逐字稿或完整聽打。
- 拍攝表為 14 支；各路徑的實際片長以 [媒體 QA](media-qa.md) 為準。一輪僅經過其中一個時間分支，加上選項思考及男主回應約 4 分鐘。詳細台詞與人物動作見 [v3 拍攝稿](night-market-video-prompts-v3.json)；製作目標與真機驗收狀態分開記錄。
- Leah 是成年、可見且有自己的茶與朋友行程；她的笑、回問、停留不自動變成喜歡。
- 每次玩家選錯，只重播一個關鍵節點；自然播片不因環境中斷而停住，文字選擇才停。
- 忙但願意稍後聯絡、當下短即約、明確拒絕與舒服離場都有各自回顧，不以收號評分。
- Sydney 提示短、少、可行動；不洩露 Leah 心聲，不搶答，也不在 Leah 發話時長講。
- 回顧至少指出一個做得好的具體行為與一個漏接的資訊，對應方法卡與可重試節點。

## 現行 MVP source 對齊（2026-09-07）

本節以 repo 現行 `lib/features/night_market/data/night_market_story.dart` 為準，補充前述研究歸納之後的實際產品敘事；較早的 prompt 草稿與研究主張不在此覆寫。完整對白、選項文字、caption 時間與路徑 ID 仍以 story source 為單一真實來源。

從頭到尾的有限影片流程是：Sydney 以 `establish` 陪玩家進夜市，`hesitate` 提供吐氣與走近／繼續逛的選擇；走近後經 `opening → concern`，玩家先說明來意，再回應 Leah 對推銷的疑慮；`work` 交換工作資訊，`craft` 以職能治療、陶杯與歪杯故事建立共同話題，`tease` 以「至少還用得上。你很常跟女生打招呼嗎？」接續；`call` 呈現無糖烏龍叫號與 Leah 等茶。之後由預先指定的 run variant 進入 `available` 或 `busy`，不是玩家代替 Leah 判斷意願。

- `available`：Leah 說朋友還要二十分鐘才來、還能逛一下，並問旁邊是否賣陶杯。玩家可邀請「去旁邊逛兩分鐘手作攤」（`invite_craft_stall → date → decline → coach`，一起看杯後友善道別），或說「那我們先各自逛，今晚玩得開心」（`leave_available → decline → coach`）。共用的 `decline` 是內部 asset ID，此分支不是拒絕。
- `busy`：Leah 說朋友在前面等，但補充杯子故事蠻好笑。玩家可提出「妳願意的話我留我的，改天喝無糖烏龍；不用現在回」（`offer_contact → contact → coach`），或「了解，祝妳今晚逛得開心，再見」（`respect_busy_bye → decline → coach`）。低壓邀約只出現一次，不把交換聯絡方式當成必然結果。
- `hesitate` 的 `keepwalking` 進 `pause_ending` text-only ending，僅文字復盤；一般結局才回到 `coach`，其後可再練 opening 或 craft 關鍵點。

肯定感落在真實可見節點：opening 的米色外套與來意、craft 的手作與陶杯回應；流動感落在先接住 Leah 的推銷疑慮、工作資訊與提問；娛樂感落在共同夜市、叫號與歪陶杯笑點。Sydney 的 hint 應在 NPC 影片完成、玩家需要選擇的階段出現，不替 Leah 解讀，也不在她發話時搶答。busy/available 是不同的時間與可用性條件；劇本只給一次小型、可拒絕的邀約，離場與尊重自己步調也都是有效結果。現行三種正常結尾是：一起看杯後友善道別（`date → decline`）、忙碌時交換聯絡方式後道別（`contact`），以及其他友善或明確收尾（`decline`）；內部 asset ID 不等於產品語意。

本輪是有限互動影片分支 MVP：14 個 video beats（`establish, hesitate, opening, concern, work, craft, tease, call, available, date, busy, contact, decline, coach`），另有 `pause_ending` 文字結束；不是 Unity 自由 3D、不是動態 AI 女主，也不把影片歷史傳入 Leah 文字對話。手機路徑是 Learning → 夜市卡 → 影片分支 → 復盤三篇心法（文章 1／11／21 的短卡，全文入口沿用既有文章 read gate）→ 重練關鍵點；文字練習是可選延伸，CTA 顯示「到圖鑑繼續文字陪練」並導向 `/practice-collection`。圖鑑 profile deeplink 須先解鎖才能使用，且文字對話不帶入夜市影片 context。

## 研究證據限制（現行表述）

20 支研究影片已做全時間軸 1 秒 OCR 與抽幀索引，並對少數節點抽核；這支持畫面字幕、章節與大致時間定位。研究沒有完成 20 支影片的全音訊逐字轉錄、全量聲調核驗或全量身體動作標註，因此不能聲稱全片聲音與動作都已驗證，也不能把 OCR 索引當成 ASR 或母語者聽核結果。時間碼仍可能有約 ±2 秒誤差；產品影片的實際音訊與字幕，另以媒體 QA 報告及現有 story caption 驗證。
