# 夜市直式情境：文案與分鏡對稿 v1

狀態：供 Eric 對稿，尚未核准拍攝。本稿不代表影片已生成或已接進 App。
男主名為 Chris，自我介紹使用「你好，我叫 Chris」。Sydney 是同行朋友與教練；Leah 是有自己行程的成年女生。

## 來源與改編邊界

主參考是 [達人篇 07](https://drive.google.com/file/d/1qe_r7a0JXQycOJajqrj2C-6UH5GBYrYL/view) 19:14–21:42 的小王實例：飲料開場、穿著觀察、對方問「你認識我？」、聊就學與購物吃飯、朋友在旁、道別。19:14 的字幕可核對「（小王）哈囉 我問一下這個好喝嗎」。其他定位與研究限制見 [詳細筆記](tests-notes.md)。這不是 Chris 本人搭訕的逐字紀錄，也不把本稿的夜市台詞冒稱原片原話。

輔助參考：[解惑篇 07](https://drive.google.com/file/d/1x4lopyHNOQryPDLPIaajDjrAC67gNPzQ/view) 01:18–03:17、16:15–16:17，女生的推銷疑慮與附近推銷活動有真實情境關聯；不能一概當玩笑。[達人篇 08](https://drive.google.com/file/d/1r4GM139lVrppjkEDOdlHmLi5h7Pngzqa/view) 05:36–07:19 是先確認時間、再提附近小活動的教學；部分即約現場缺收音，不補造原對白。

以下所有 Chris／Leah／Sydney 對白是為台灣夜市重新寫的原創改編。時間只估表演節奏，不含玩家選擇停留時間。

## 場景與鏡頭約定

- 原生 9:16 構圖。第一人稱眼高；Sydney 同行時在右側，Leah 正面交流時在畫面中上方。保留環境、完整臉部和拿飲料的動作，不把 16:9 原片中央放大當正式直式版本。
- 地理位置固定：飲料攤靠右，前方可見地瓜球攤；通道保持可走。開場先看得到攤位與其他人，再自然注意到 Leah。
- Leah 正在點無糖烏龍、取杯和等朋友。手機只有收到朋友訊息時才取出；杯子持續同一隻手，不瞬移。
- Sydney 在靠近前小聲鼓勵，然後到旁邊買東西，不站在两人中間。對話中的 hint 是玩家看見的介面提示，不是 Sydney 在旁邊大聲報答案。
- 對話泡泡在場景內，保持臉部可見。播放時只顯示當下那句；關鍵選擇才停，不把每句話都拆成一道選擇題。

## 分支對白：不是所有反問都同一種反應

**沒聽清楚／誤解**（對應原例「你認識我？」）：

Leah：「蛤？你認識我喔？」
Chris：「還不認識，剛剛是說想認識妳。你好，我叫 Chris。」
Leah：「喔，原來是這樣。」
Sydney 僅在玩家遲疑或主動點 hint 時顯示：「她沒聽清楚，重說就好。」

**真的懷疑推銷**（不與前一分支每輪疊加）：

Leah：「你是要推銷什麼嗎？」
Chris：「不是，我沒有要賣東西。就是剛剛看到妳，想認識一下。」
如果她放鬆並繼續問，才回主線；如果仍說不用，就收尾。
Sydney：「先回答她問的。」

**同樣是『你常這樣嗎』，Chris 可有不同性格回應**：

- 比較直接：Chris：「偶爾。今天看到妳，就想過來聊一下。」→ Leah：「回答滿直接的欸。」
- 比較坦白：Chris：「偶爾，但每次走過來還是會緊張一下。」→ Leah 笑：「看得出來，你剛剛講有點快。」Chris：「好，那我慢一點。」

後續影片必須對應玩家真的選了哪句；不能兩種回答都接同一段不相干反應。緊張不是自動扣分，能察覺並調整才是可練習的行為。

**Sydney 被誤認成女朋友**（可留作下一次變體，不必擠進本輪主線）：

Leah：「剛剛那個是你女朋友喔？」
Chris：「不是，是我朋友。她剛去買吃的。」
若 Leah 帶笑追問：「她叫你來的？」
Chris：「她有催一下。但想認識妳是我自己。」

## Sydney 的用法與三種感覺

- 肯定感：知道自己想認識，願意清楚說出來；hint「想認識，就說清楚。」不講長篇配得感理論。
- 流動感：她問附近、朋友、吃的，就回這些真實資訊；hint「先接她這句。」不要每次都給玩家下一句標準答案。
- 娛樂感：從『只是走走結果都在吃』『不是只研究飲料』產生共同笑點，不每句都硬撩。
- 自動提示最多放在靠近前與第一次明顯卡住；其餘讓玩家主動叫 Sydney。沒有需要時，她就安靜。
- 復盤只講一個剛發生的細節：例如「她問你是不是住附近，你先回答，話題就接上了。」或「她說朋友到了，你有收住，沒有再把她留下來。」之後提供對應文章與片段重練。

## 聲音與生成規格：待對稿後才製作

Chris：成年台灣男性，日常台灣華語，中低音但不刻意壓嗓；音量正常、短停頓、句尾自然收住。Chris 的英文名字自然念出，其餘句子維持台灣中文語調。

Leah：成年台灣女性，像在夜市與陌生人說話，從一開始的確認，到有興趣才慢慢放鬆；不嗲、不全程笑、不把每句都說成撒嬌。

Sydney：成年女性朋友兼教練，口吻俐落、帶一點玩心；靠近前小聲說話，介面 hint 不混成場內配音。

三人各自固定同一份核准聲線；先對稿，再聽短試音，確認口音與節奏後才批量製作。Prompt 要包含角色、場景、精確台詞、每句說話者、發話時機、視線與持物連續性、原生 9:16 構圖；但口音與自然度不能只靠文字承諾，仍以試音驗收。

台詞音轨与环境底音分開；環境 loop 不得含角色對白。每片完整聽查開頭、中段、結尾與重複句，不能只用一次 ASR 摘要替代聲音驗收。
