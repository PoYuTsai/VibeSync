# 開場救星：開場白的底氣（研究備忘）

- 日期：2026-09-27
- 分支：`claude/opener-confidence-tone-6f9p6z`（只做研究：沒改程式、沒 commit、沒 push、沒呼叫付費模型）
- 依據：repo HEAD `42eb022` 的程式碼與 `tools/opener-plan-write-eval` 語料

新版開場救星會寫出「問妳一個沒營養的問題」「問個無聊問題」「隨口說說」這類替自己打折的句子。這份備忘整理它們從哪裡來、為什麼會發生，以及建議怎麼改。

## 結論

這三句是寫手 prompt 的設計造成的，不是模型偶爾抽風。寫手 prompt 每一條規則都在降低她回覆的負擔，沒有一條規定用戶該用什麼姿態說話。模型要把一句話變得低壓、好回，最省事的做法就是在句子裡直接宣告這題不重要。挑卡和評測也都不檢查這件事，所以其中一句還被選成了 AI 推薦。

要的語氣：**理所當然的自信、不猶豫、說的話有份量**；但自信不是強硬，對陌生人開場仍要有禮貌。

## 截圖裡的三句

截圖上的卡片名稱只有新流程「規劃 → 寫手 → 挑卡」會用到。這條路要旗標 `OPENER_PLAN_WRITE=true`，而且新版 App 送出 `openerCardSet=2`（`opener_flow_handler.ts:667`）。卡片名稱對應寫手的五個欄位：直接接話＝extend、換個角度＝resonate、換個方向＝tease、輕鬆一點＝humor、帶到自己＝coldRead（`opening_rescue_screen.dart:163`）。

| 卡片 | 原句 | 打折方式 | 改法（示意） |
|---|---|---|---|
| 輕鬆一點（humor） | ~~問妳一個沒營養的問題，~~妳今天午餐吃什麼 | 先請示，再貶低自己的問題 | 今天午餐吃了什麼好料 |
| 輕鬆一點（humor） | ~~問個無聊問題，~~妳是那種會重複刷同一部劇的人嗎 | 貶低自己的問題 | 重刷最多次的是哪部劇 |
| 直接接話（extend）**AI 推薦** | 最近有沒有迷上什麼新東西~~，隨口說說~~ | 叫她隨便回，順便降低這則的份量 | 最近迷上什麼新東西 |

- 前兩句的來源指令：「同一件事，語氣輕鬆一點的問法」（`opener_write.ts:48`）。
- 第三句的推薦理由寫著「問題夠開放又不預設立場，她可以隨便挑一件事聊」，幾乎是把沒線索時的那行指令原封講回來：「開一個不預設她任何事實、她好回答的低壓話題」（`opener_write.ts:101`）。改法也拿掉了「有沒有」，直接假設她有答案，不先給她「沒有」的出口。
- 三句都沒接到她的任何資料。截圖把對方資料解讀收起來了，所以「這幾局沒有可接線索」是推測。
- 改法只是給人看的示意，不放進 prompt。拿掉打折的話之後直接問就好，不必反過來加命令或條件（像「不准回隨便」），那對陌生人太強硬，是另一種用力。自信是理所當然地問，禮貌是不逼她。

## 為什麼會這樣

### 已從程式碼確認

1. **寫手 prompt 從第一版就沒有姿態規則。** `opener_write.ts:22-33` 全部在講她：好回、不用接受考核、不用配合演出、「問號多像在索取資訊」。9/25 第一版（`04847f9`）就是這樣。舊版 prompt 原本有「框架維持：評價權留在自己手上」「非乞求感」「長度本身就是位階訊號」（`opener_prompt.ts:152`、`:270`、`:285`），重寫時沒帶過來。
2. **「輕鬆一點」的定義本身就在要求打折。** `opener_write.ts:48` 規定問題本身不變、只換語氣，模型能動的只剩句首和句尾。中文聊天裡「輕鬆」最現成的講法，正好是「問個無聊問題」。三句裡有兩句出自這張卡。
3. **沒線索時的指令只有降壓詞，沒有做法。** `opener_write.ts:101` 寫「不預設她任何事實、她好回答的低壓話題」。沒有具體素材能讓題目本身變好回，模型就改用嘴巴宣告「隨口說說」。
4. **挑卡沒有防線。** `opener_pick.ts:115-138` 檢查紅線、兩個問號、長度、照抄自介、自述位置、外文字。打折句一分都不扣，所以「隨口說說」那句能被選成 AI 推薦。
5. **評測看不到這個問題。** `tools/opener-plan-write-eval/cases.json` 的 22 題每題都有 1–3 條線索，沒有一題走沒線索那條路。評審代碼（`judge.ts:15-45`）沒有「替訊息打折」這一項。Bruce 的校準與盲測語料共 204 句，一句打折句都沒有。

專案其實已經有這個概念：analyze-chat 的語意評審 `beta_pattern` 裡就寫著「為表達興趣道歉」（`_shared/social/semantic_critic.ts:244`），只是開場救星沒用到。

### 推論（還沒用付費測試驗證）

「問號多像在索取資訊」可能讓模型覺得開口問就是在跟她拿東西，於是先道歉。這只算次要誘因。

## 建議怎麼改

### P0：寫手 prompt（`opener_write.ts`，只影響新版 App）

**① 在 `SENTENCE_RULES` 後面加一段姿態規則（兩種卡組共用）**

```
## 說話的姿態：理所當然
- 這則訊息本來就值得她回：第一個字就是內容，不先替它打折。
- 不評價自己的問題（無聊、沒營養、蠢、亂問、隨便問問）；不請示、不預告（問妳一個問題、想請問、不好意思、打擾一下、冒昧）。
- 不替她降低回答的份量（隨口說說、隨便回、想到什麼說什麼、不回也沒關係）。
- 好回答靠題目具體、她一句就能答，不是靠說這題不重要。低壓是她回得輕鬆，不是你講得心虛。
- 自信不是強硬：不命令、不催、不給她條件（不准回隨便、一定要回、快說）；直接問，語氣還是像對朋友那樣客氣。
- 每則寫完，遮掉開頭那段鋪墊或句尾那段補充再讀：意思沒變，就刪掉。
```

**② 輕鬆一點（第 48 行）**

```diff
- humor（輕鬆一點）：同一件事，語氣輕鬆一點的問法。
+ humor（輕鬆一點）：同一件事，用一個好玩的畫面或小誇張讓它輕鬆；輕鬆來自內容，不是把問題說成無聊、叫她隨便回或加開場白。
```

**③ 沒線索分支（第 101 行）**

```diff
- 她的線索都不適合：開一個不預設她任何事實、她好回答的低壓話題
+ 她的線索都不適合：開一個不預設她任何事實、她一句就能回答的具體小話題；直接問，不說這題無聊，也不叫她隨便回
```

這些改動不會動到現有測試檢查的字串，另外補一條測試確認新規則有在 prompt 裡。刻意不放正面示範句，因為 repo 已經吃過示範句被逐字照抄的虧（`opener_prompt.ts:194`，還有「環河公園」）。

### P1：舊版 App 和旗標關閉時的路徑（`opener_flow_prompt.ts`）

舊 prompt 一樣沒有姿態規則。`:94` 寫「低壓話題」，`:112` 寫「誠實的低假設話題」，「誠實」很容易被讀成「承認這題很普通」。建議加同一段規則，這兩處照 ③ 的方式改。

### P2（選配，需要 Eric 決定）：伺服器端直接拿掉打折句

仿照現在「emoji 直接拿掉」的做法（`opener_pick.ts:66` 的 `withoutEmoji()`），在 `opener_pick.ts` 加一個函式：句首或句尾整個子句是打折句才拿掉，拿完少於 6 字就保留原句。套用在 `opener_plan_write.ts:329` 和 `:386`，並記 telemetry。

離線檢查（免費，沒有呼叫模型）：

| 檢查 | 結果 |
|---|---|
| 打折句正確拿掉 | 8 / 8 |
| Bruce 語料（204 句）被誤改 | 0 / 204 |

檢查用的規則草稿，實作時再收斂：

```js
// 句首：請示、替問題打折的整個子句（後面要有標點）
const HEDGE_LEAD_RE = /^(?:欸|那個|先|我)?(?:(?:問|請教)(?:妳|你)?(?:一)?(?:個|下)?(?:很|有點|超|比較)?(?:無聊|沒營養|蠢|白癡|廢|奇怪|私人|冒昧)?(?:的)?(?:問題|的)|(?:隨便|隨口|亂)(?:問問|問一下|問)|冒昧(?:問一下|請問)?|不好意思|打擾(?:一下)?|想請問)(?:喔|啦|哈+)?[，,：:、\s]+/u;

const HEDGE_TAIL_RE = /[，,\s]+(?:就)?(?:隨(?:口|便)(?:說說|講講|聊聊|回回|回)|不用想太多|想到什麼說什麼|不回也沒關係|隨便問問|亂問的|沒營養的問題|無聊問題)(?:啦|喔|哈+|就好|而已)?[。.]?$/u;
```

限制：換句話說的版本抓不到（例如句中的「這題有點廢」），主力還是 prompt。這跟 9/25「不靠詞表」的方向有點張力；不過那條講的是讀用戶補充，輸出端本來就有 emoji 與黑名單的前例。

### 評測：把這個問題放進評測

- `cases.json` 補幾題沒線索的局：只有名字、只有一張自拍、自介只寫 hi、篩選型自介沒有正向線索。
- `judge.ts` 加評審代碼 `self_discount`：(a) 句首或句尾有一段在評價這則訊息、請示，或叫她隨便回，而且 (b) 拿掉後意思不變。要附逐字證據。
- 付費 A/B（例如 6 題 × 3 次 × 新舊 prompt）照 README 規矩要 Eric 說「跑」才執行，依現有單價推估約 US$1。
