## 1. 所有文章都要遵守的規則

### 1.1 寫作格式（畫面只認這幾種符號）

文章內容是放在 Dart 字串裡的簡化 Markdown，`article_detail_screen.dart` 的解析器只認：

- `## ` 大標、`### ` 小標
- `- ` 條列
- `**粗體**`
- 行首 ✅ 或 ❌（會變成綠勾／紅叉圖示）

**不要用**：表格（會直接顯示一堆「｜」，文章 5 就是這樣壞掉的）、`>` 引用、有序清單（`1.` 只會當普通文字，可以用但不會縮排）。

其他慣例：全形標點；一段最多三句；每篇 6～8 個大標；1,000～1,600 字；最後一節固定叫「今天的練習」，給三個問句或一個具體動作（跟文章 21～24 一樣）。讀者用「你」，例句裡對她說話用「妳」。

### 1.2 電子書已經定好的 11 條規則（文章也要一致）

這 11 條是 2026-09-03 電子書優化時定的「跨冊統一規則」（ADR #45 明寫日後新增教材也要遵守）。白話版如下，括號裡是定稿原句，寫到相關主題時直接沿用原句最安全。

1. **她說出口的話最優先。** 她明確說不要、或畫了界線，就以她說的為準；只有她的話真的很模糊時，才看一段時間反覆出現的行為。不用猜測推翻她說出口的答案。（「明確的拒絕或界線，永遠排在最前面」）
2. **看一段對話，不看一句。** 一則訊息只能算線索；先看前後三到五則，她有沒有主動補內容、回覆是否持續。（「一則訊息只能算線索」）
3. **刁難的話不一定是測試。** 可能是好奇、開玩笑、確認界線，也可能是她不舒服。先看語氣和前後文，再決定直接回答、輕鬆接，或停下來確認。（「不是每個問題都是測試」）
4. **邀約先丟「種子」。** 先提一個具體活動、暫時不定時間，看她想不想接；她明確答應後，一到兩輪內敲時間。「改天約妳喝杯咖啡」太空泛；玩笑式的邀約不算同意。（「她明確答應後，再在一到兩輪內敲時間」）
5. **提案要具體，而且留一個好回答的口。** 說清楚活動、時間、地點，最後加一句她容易回答的確認。不替她決定。（「週四晚上七點去那家店？妳可以的話，我就訂位。」）
6. **確認是告知，不是再問一次。** 雙方同意後簡短確認；她沒有否認，不等於她答應了。（「明天七點一號出口見；妳臨時有變再跟我說。」）
7. **被拒絕就先接受。** 她給另一個時間就一起改期；沒有替代方案，就不要立刻再約。（「她說不行，就先接受」）
8. **快回不是問題。** 長期回得比對方多很多、節奏完全繞著她轉才是失衡。忙就晚點回，想聊就正常聊，不用計時器。（「快回不是問題」）
9. **吵架不等於關係結束**，也不能拿來證明她在乎。（「吵架不等於關係結束」）
10. **穩定可以保留，但要有自己的偏好。** 問題不是穩定，是整段互動只剩附和。（「問題不是穩定，而是整段互動只剩附和」）
11. **玩笑只開在情境上。** 不拿身體、外貌、家世這些她不容易改變的事當笑點；她沒接就換方向。（「她沒接，就換方向」）

### 1.3 不能出現的句子

`tools/content/audit_rules.json` 的禁用詞，目前只自動掃電子書，文章要人工檢查。寫完跑這段（有命中會印出來）：

```bash
python3 - <<'EOF'
import json
rules = json.load(open('tools/content/audit_rules.json'))
src = open('lib/features/learning/data/articles_data.dart', encoding='utf-8').read()
hits = [p for p in rules['bannedPhrases'] if p in src]
print('禁用詞命中：', hits if hits else '無')
EOF
```

禁用詞白話對照：「行為＞情緒＞字面」「行為＞字面」（用行為推翻她的話）；「拒絕階梯」「拒絕要有成本」「下次奶茶妳請」（讓拒絕有代價）；「假定同意」「假定式推進」（當她已經答應）；「反應等級等於她目前認定你的價值」（她冷＝你沒價值）；「聊什麼占 7 分」（把 7% 當真）；「改天約妳喝杯咖啡」「週四晚上七點，我訂位」（太空泛／替她決定）；「她冷的不是你」「代表她還在乎」「跟妳一樣短腿」「做流氓般的紳士」「沒有否認『見面』」。

### 1.4 不能教的東西（一句話版）

寫任何一篇之前先對一遍。完整的教材出處對照在前一份報告第 4 節。

- 「她嘴上說不要、身體沒動就是可以」，以及任何用身體反應推翻口頭拒絕的說法。
- 「沒有反應就是好反應」「沒紅燈就是綠燈」。
- 讓拒絕有代價（「放我鴿子下次請我喝奶茶」）。
- 當她已經答應、不留她說不的空間（「妳的號碼是多少」當唯一句型、「假定了場景她就無法拒絕」）。
- 故意忽冷忽熱、故意不回、假裝有別人、讓她不安來留住她。
- 先否定她、等她證明自己、再否定，讓她一直努力（第 3 冊已列為反效果技巧）。
- 幫她把退出的理由先講掉（「我知道妳明天要早起……」）——第 3 冊列為反效果，教材說可以，**等 Eric 決定**（第 4 節）。
- 把她回得冷說成「她覺得你價值低」。
- 介入她跟男友的關係。
- 兩性策略世界觀（女人天生怎樣、年齡曲線、紅藥丸）、Alpha／Beta 標籤、九條鐵律、格言。
- 線下肢體推進的步驟、「撤臉不後退」「第三次再擁抱」之類。
- 交往後的關係維護（抽離、誰該先談關係定義）——超出目前產品階段。

### 1.5 每篇新文章要動到的程式與資產

- **資料**：在 `lib/features/learning/data/articles_data.dart` 的 `articles` 清單最後加一筆 `Article(...)`；id 用字串遞增（`'25'` 起）。
- **封面圖**：`assets/articles/article_N.jpg`，直式 600×883、約 80～120 KB、深色或壓暗的照片（卡片上會疊白字）。一篇一張，不能共用（`article_cover_assets_test` 會擋缺圖與重複）。`pubspec.yaml` 已含整個 `assets/articles/` 資料夾，不用改。
- **分類與顏色**：`category` 只用既有四個（核心社交心法／深度交流／幽默與調情／非語言溝通），對應 `categoryColor`：核心社交心法與非語言溝通用 `'yellow'`，深度交流用 `'coral'`，幽默與調情用 `'pink'`。分類篩選 chips 會自動長出來，不用改畫面。
- **來源欄位**：教材改寫的文章統一 `source: 'VibeSync Original / 教材改寫'`、`sourceUrl: 'https://www.vibesync.app'`（比照文章 24）。
- **練習卡分類**：`_practiceCategoryForArticle` 依 id 決定練習卡。沒列在 switch 裡的，照分類預設：幽默與調情→「性張力與曖昧」、深度交流→「延伸與共鳴」、其他→「穩住自己」。要落在「判斷與邊界」「推進與邀約」「開話題」的文章必須把 id 加進 switch（第 3、4 節每篇都有註明）。
- **測試**：`test/unit/features/learning/article_practice_guide_test.dart` 為每篇需要手動對應的文章補一個斷言；封面測試不用改。
- **驗證指令**：`flutter test test/unit/features/learning/ test/widget/features/learning/`，再跑 1.3 的禁用詞腳本。

### 3.1 id 25｜她忽冷忽熱？那本身就是答案

這篇在教什麼（一句話）：別再猜她一句話的意思，看她這兩週做了什麼；她說出口的話永遠優先。

| 欄位 | 值 |
|---|---|
| id | `'25'` |
| title | 她忽冷忽熱？那本身就是答案 |
| subtitle | 別再猜她那句話的意思，看她這兩週做了什麼 |
| category / categoryColor | 核心社交心法 / yellow |
| source / sourceUrl | VibeSync Original / 教材改寫 / https://www.vibesync.app |
| readTime | 6 分鐘 |
| imagePath | assets/articles/article_25.jpg |
| 練習卡 | 判斷與邊界（要把 `'25'` 加進 switch） |

```
## 你在猜的那句話，其實不重要

很多人卡在同一個地方：她上週還會主動傳訊息，這週回得又慢又短。你把她最後那句「哈哈好啊」看了二十遍，想知道她到底是什麼意思。

先說結論：一句話猜不出答案。答案在她這兩週做了什麼。

## 先看一段時間，不看一則訊息

一次晚回不算什麼。她可能在忙、在累、在跟朋友吃飯。

但如果連續兩三週都是：你開話題她才回、你不傳她就消失、約她永遠「再看看」。那不是混亂的訊號，那就是訊號本身。

規則很簡單：一則訊息只能算線索。先看前後三到五則，她有沒有主動補內容、有沒有反問你、有沒有提到下次。

## 四個問題，代替你腦中的猜測迴圈

與其問「她那句什麼意思」，改問這四題：

- 她會不會沒事也傳訊息給你，而不是只有需要你的時候？
- 你開玩笑，她接不接？還是每次都冷冷帶過？
- 有沒有任何一次，是她先提「要不要見面」「哪天有空」？
- 她會不會為你做一點小事，不求回報？例如記得你說過的話、主動分享她的日常。

四題裡有三題是「沒有」，你已經有答案了，不需要她親口說。

## 她說出口的話，永遠排在最前面

這篇不是教你「不用聽她說什麼」。剛好相反。

如果她明確說了「最近不想聊」「我們當朋友就好」，那就是答案，不必再從行為裡找希望。

只有在她的話真的很模糊的時候，才用上面四題看一段時間的行為。不要用猜測推翻她說出口的話。

## 看懂之後，你能做的只有一件事

不是質問她「妳是不是對我沒興趣」，也不是傳一段長訊息分析你們的關係。

是把注意力拿回來：回去做自己的事、見朋友、跟其他人聊。訊息可以照常回，但不要再是你一個人在撐。

如果她之後回來找你、主動補了內容，你會知道，因為那會很明顯。真的有興趣的人，不會讓你猜。

## 今天的練習

打開一段你最近在猜的對話，往上滑兩週：

1. 她主動開話題幾次？你幾次？
2. 她有沒有提過任何一次見面或下次？
```

```
## 告白為什麼常常把人嚇跑

很多人把告白當成開始：先說清楚我喜歡妳，她答應了，關係才算開始。

但對一個還在認識你的人來說，「我喜歡妳，妳要不要跟我在一起」是一個要立刻回答的大問題。她還沒想清楚，就被推到要選邊的位置。多數人在這種壓力下，會選比較安全的那個答案：拒絕。

## 先分清楚兩件事：說喜歡，和談在一起

這兩件事常被混在一起，其實完全不同。

- **說喜歡**：「妳講工作那段我一直記得，蠻欣賞的。」這是表達，可以隨時說，越具體越好。
- **談在一起**：「我們要不要交往？」這是要她做決定。

前者不用等。把喜歡憋著不說、怕她知道，是害人最深的老觀念之一。後者要等，因為那是要她給一個她可能還給不出來的答案。

## 她也在靠近你，長什麼樣子

「在一起」該不該提，不看你有多喜歡她，看她有沒有這些動作：

- 她會主動找你，不只是回你。
- 你們見過面，而且她願意再約。
- 她開始說「我們」：我們下次去、我們上次那家。
- 她會問你私人的事，也會講她自己的。

這些出現了，告白只是把已經發生的事說出來。這些還沒出現，告白是在要一個她給不了的答案。

## 告白是確認，不是開始

換個順序：先讓靠近的行為累積，最後才用一句話確認。

到那時候，你要說的不是「妳願不願意」，而是「我們現在算什麼？我是想認真跟妳在一起的。」她多半已經知道你要說什麼，因為她自己也在往這個方向走。

很多時候，甚至會是她先問你。

## 如果你已經說了，她沒答應

不追問為什麼，不解釋你有多認真，不自我貶低。

可以說：「了解，我說出來是因為想讓妳知道。不用有壓力，我們照常聊。」然後真的照常。

她說不，就先接受。她之後仍願意聊天，不代表她改變了答案；如果哪天她真的改變了，她會讓你知道，不需要你再問一次。如果互動變成單向，答案也一樣清楚。

## 今天的練習

1. 寫下你想對她說的那句「喜歡」，看它是在表達，還是在要她決定。
2. 上面四個「她也在靠近」的動作，她出現了幾個？
3. 如果一個都還沒有，這週先做一件讓你們更靠近的事，例如約一次見面，而不是告白。
```

```
## 對話卡住，通常不是沒話題

她說「我上週去台南玩」。你腦中一片空白，最後回了「哦不錯耶」。對話就停在那裡。

不是你沒東西講，是你只看到一種接法。其實同一句話，至少有四種方向可以接。

## 四種接法

還是用「我上週去台南玩」當例子：

- **接事實**：「去幾天？有去安平嗎？」（問發生了什麼）
- **接感覺**：「是吃得很滿足，還是熱到只想躲咖啡店？」（問她怎麼體驗）
- **接故事**：「我上次去原本只想吃一家，最後變成一路加碼。」（給自己的經歷）
- **接想像**：「我們一起去，大概需要一個人負責喊停。」（把兩個人放進一個畫面）

接事實最安全，但連續三次就變成問卷。感覺、故事、想像才會讓對話有溫度。

四種接法是備選，不是清單。她一句話，你回一種就好。

她回得短，就換一種方向試試；她接了，就往那個方向多走一步。

一次丟四個問題，她會不知道先回哪個，最後哪個都不回。

## 接住她，也要帶出你自己

最常見的死法是：你一直問，她一直答，對話裡沒有你。

所以「接故事」和「接想像」特別重要，因為那兩種一定會帶到你。

一個簡單的檢查：往上滑，你的訊息裡有沒有三分之一是關於你自己的？如果幾乎沒有，她其實不認識你。

✅ 她：「我週末去露營。」你：「我喜歡早上在山裡喝咖啡，搭帳篷就沒那麼浪漫了。」
```

```
## 第一次見面最常見的錯

很多人第一次見面就訂一家很貴的餐廳，覺得這樣才有誠意。

結果是：兩個人面對面坐兩個小時，像面試。花了錢，氣氛卻很僵。

約會不是用花錢證明什麼。它是兩個人一起經歷一點什麼，然後有東西可以記得。

## 短一點，能講話，然後換個地方

第一次見面的三個原則：

- **時間短**：一到兩小時就好。好聊可以延長，不好聊也不會被困住。

同樣聊兩小時，一直坐在原位感覺很短；換了兩個地方，會像認識很久。這也是為什麼旅行的時候，感情特別容易變快。

選地點的口訣是「你熟、她方便」。

- 在她方便的區域挑，不要讓她跨半個城市來找你。
- 在那個區域裡，挑你去過、知道好不好的店。你熟的地方，你會比較穩，不用邊看菜單邊緊張。

提案的時候把活動、時間、地點一次說清楚，再留一個好回答的確認口：「週四晚上七點去那家店？妳可以的話，我就訂位。」
```

```
## 被拒絕的那一刻，最想做的三件事都別做

你約她，她說「最近有點忙」。你告白，她說「我們當朋友就好」。

那一刻最想做的三件事是：問她為什麼、解釋你其實沒那個意思、或說一句「也是啦，我本來就配不上妳」。

這三件事都會讓情況更糟。不是因為她會生氣，是因為它們都在把一個已經結束的問題，硬拉回她身上。

先記住：「最近有點忙」和「我們當朋友就好」是兩種不同的拒絕，最後一節會分開講。

## 不追問為什麼

「為什麼？是我哪裡不好嗎？」聽起來是在了解，其實是在要她負責解釋你的感受。

多數時候她也說不出一個你能用的理由。時間不對、感覺不到、她有別的事，這些都不是你能修的。

她說不行，就先接受。她主動給另一個時間，就一起改期；沒有替代方案，就不要立刻再約。

## 不幫她想理由

被拒絕之後，很多人會自己補完整段推理：一定是我不夠高、賺得不夠多、上次那句話說錯了。

這些是你腦中的劇本，不是她的。你替她把門關上了，還順便把自己的價值也判了刑。

把「我做得對不對」和「她要不要」分開看。你可以每一步都做對，她還是可能沒興趣。這不是你的失敗，兩個人的事本來就需要兩個人都要。

## 不認真自貶

自嘲可以：「好，看來我的咖啡店推薦還需要練習。」

認真自貶不行：「我就知道，我這種人本來就沒人要。」

前者讓氣氛鬆一下，後者是在要她安慰你。她拒絕了你，還得負責安撫你，這對她是壓力，對你是第二次失分。

## 可以說的話

- 「了解，那先這樣，妳忙完再說。」
- 「好，沒關係。我說出來是想讓妳知道，不用有壓力。」
- 「沒事，之後有剛好的時間再約。」

說完就真的放下，回去做自己的事。訊息可以照常聊，但不要用更多訊息證明你不在意。

## 之後呢：先分清楚她拒絕的是哪一件事

被拒絕有兩種，之後的做法完全不同。

- **她只是那次沒空**（「最近有點忙」「那天不行」）：之後她主動提到想去的活動、或說出她有空的時間，可以再提一次邀約。她沒有再提，就不要再約；最多隔一段時間換個方向試一次，第二次不行就結束。
- **她已經說了只想當朋友**（「我們當朋友就好」「我沒有那個意思」）：那就是答案，就按朋友相處。她之後仍願意聊天、仍會分享日常，不代表她改變了答案。如果哪天她真的改變了，她會讓你知道，不需要你再問一次。

如果變成你一個人在撐，答案已經很清楚，不需要第三次確認。

被拒絕會發生很多次，這很正常。你要練的不是避免被拒絕，是被拒絕之後，還能好好過日子、還敢再開口。
```

## 4. WP3：新增第二批 6 篇（id 31～36）

這批先給大綱與關鍵句，不給全文；等第一批上線後看閱讀數據再決定順序。每篇的「大綱」就是文章的大標，底下是那一段要寫什麼。

### 4.1 id 31｜好人卡是怎麼發出來的

- **一句話**：一段關係要往前走需要三個零件；好人卡是缺了「現在聊得開不開心」這一塊，就急著表白。
- **欄位**：核心社交心法／yellow／6 分鐘／`article_31.jpg`／練習卡：判斷與邊界（把 `'31'` 加進 switch）。
- **大綱**
  - `## 認識很久、聊得很好，卻只差一件事`：開場情境。認識半年、每天聊天、一表白就變成「我現在不想談戀愛」。
  - `## 一段關係有三個零件`：認識多久與什麼身分（只能靠時間）；現在聊得開不開心（每一則訊息都能影響）；有沒有實際往前走（見面、說一句具體的喜歡、曖昧的玩笑）。
  - `## 三個零件湊不齊，會變成什麼`：三條條列。前兩個有、沒往前走：相處很開心，但一直停在朋友。認識夠久、但沒有開心和曖昧的感覺就表白：她只能說不。不熟就曖昧：她被嚇到。
  - `## 好人卡不是你不夠好，是順序錯了`：關鍵句「情緒開了，才輪得到推進」。
  - `## 怎麼把開心的感覺補回來`：開玩笑、講自己的故事、聊感覺不聊事實。點到文章 28 的四種接法。
  - `## 感覺開了，就要往前走`：約一次見面、說一句具體的欣賞；窗口會自己關。點到文章 26。
  - `## 今天的練習`：三個零件各打「有／沒有」，找出缺的那一個。
- **不能寫**：「一夜情」「耍流氓」這類字眼；「往前走」不寫成肢體接觸；不給分數表。

### 4.2 id 32｜別太快把她當成唯一

- **一句話**：越覺得非她不可，越容易把她推遠；解法不是同時約很多人，是把生活拿回來。
- **欄位**：核心社交心法／yellow／6 分鐘／`article_32.jpg`／練習卡：穩住自己（分類預設）。
- **大綱**
  - `## 「非她不可」為什麼會壞事`：一句冷回就崩、你投入遠多於她、她感受到壓力。
  - `## 你是喜歡她，還是缺選擇`：只認識一個人的時候，分不出「她很特別」和「我很缺」。
  - `## 有選擇，不等於同時約很多人`：朋友、工作、興趣、可以自己安排的生活都算。你不必把唯一的快樂押在她身上。
  - `## 她是生活的一部分，不是全部`：把行程排回來；訊息照常回，但一天的節奏不繞著她轉。點到文章 22。
  - `## 這樣做，她反而更靠近`：有自己生活的人比較好相處。這不是技巧，是事實。
  - `## 今天的練習`：列出這週三件跟她無關、你真的想做的事，排進行事曆。
- **不能寫**：「同時經營多個對象」的策略；狙擊手、霰彈槍、轉盤之類比喻；「她會吃醋」。

### 4.3 id 33｜她這句話可能在說什麼？先別急著下結論

- **一句話**：六句常見的話各有兩種意思；先當她說的是真的，再看後續行為。
- **欄位**：深度交流／coral／6 分鐘／`article_33.jpg`／練習卡：判斷與邊界（把 `'33'` 加進 switch）。
- **大綱**
  - `## 一句話可以有兩種意思`：開場。她說的話，跟她後來做的事，要一起看。
  - 六句各一個 `### `，每句寫「常見意思」和「你要看什麼」兩行：
    - `### 「我最近很忙」`：可能真的忙，也可能是委婉拒絕。看她後來有沒有回來、有沒有提別的時間。
    - `### 「你人真好」`：可能是稱讚，也可能是「安全但沒心動」。看她有沒有想繼續認識你，不要只盯這四個字。
    - `### 「我們是朋友啊」`：可能就是她清楚表達的關係方向。先照她說的，不加壓；一段時間後看互動是不是雙向。
    - `### 「我不想那麼快」`：她要求放慢，就放慢。不需要猜中她心裡想什麼才能放慢。
    - `### 「你應該很多女生喜歡吧」`：可能是玩笑試探，也可能是認真想了解。看語氣；接法見文章 34。
    - `### 「我有男朋友」`：先當事實回應，之後看互動。
  - `## 通用規則：她說出口的先當真`：規則 1 與規則 3。只有字面真的模糊，才看一段時間的行為。
  - `## 今天的練習`：找一句你最近在猜的話，寫下「她可能的意思」和「我還要看什麼」。
- **不能寫**：把任何一句寫成「一定是」；「我有男朋友」的任何進攻式處理。

### 4.4 id 34｜她丟一句很刺的話，怎麼接才不會慌

- **一句話**：刺的話可能是在玩，也可能是真問題；接法只有三種；八句常見例子各給一個示範。
- **欄位**：幽默與調情／pink／7 分鐘／`article_34.jpg`／練習卡：性張力與曖昧（分類預設）。
- **大綱**
  - `## 先分清楚：她在玩，還是真的在問`：規則 3。看語氣和前後文；分不出來就正常回答，再加一點輕鬆。
  - `## 三種接法`：承認、不解釋；輕鬆帶過，再把話題拉回來；接住、加工、丟回去。用語跟第 7 冊 3.3 一致。
  - `## 八句常見的話，怎麼接`：每句一個示範，示範後加一行「如果她是認真問：正常回答就好」。
    - 「我跟你媽掉水裡你救誰？」→「先救游泳教練，這樣妳們兩個都有救。」
    - 「你是不是在把我？」→「我還在評估。」（語氣要鬆）
    - 「你身高多少？薪水多少？」→「夠用。妳剛說那家店，後來去了嗎？」
    - 「你對每個女生都這樣嗎？」→「只對看起來會問這句的。」
    - 「你好幼稚。」→「對啊，妳這麼快就發現了。」
    - 「你為什麼喜歡我？」→ 不列優點清單，給一個具體觀察：「妳講到妳姐那段的樣子。」
    - 「你是不是很花心？」→「對啊，一週要排班，妳要先登記嗎？」
    - 「你很會聊喔。」→「今天剛好有帶嘴巴出門。」
  - `## 三件別做的事`：寫小論文解釋、反擊回去、僵住不回。
  - `## 說破就沒了`：不要說「妳是在考我對不對」。讓你的回應本身就是答案。
  - `## 今天的練習`：選一句你最怕被問的，寫三個版本：正常回答、幽默回答、保留界線的回答。
- **不能寫**：「廢物測試」這個詞；「她刁難你代表你有價值」的必然句；針對她外貌或身體的回擊。

### 4.5 id 35｜在公司和學校認識人，規則跟交友軟體完全不同

- **一句話**：職場和學校預設沒有曖昧，交友軟體預設有；用錯規則會出事；有共同活動的場合是第三種、也是最好的一種。
- **欄位**：核心社交心法／yellow／5 分鐘／`article_35.jpg`／練習卡：開話題（把 `'35'` 加進 switch）。
- **大綱**
  - `## 兩種場合，兩套規矩`：公司、學校：大家預設這裡不談曖昧。軟體、夜店：大家預設這裡就是來認識人的。
  - `## 用錯規矩的兩種災難`：在公司用軟體那套，讓人不舒服，名聲也會受損。在軟體上用同事那套（「你好，請多指教」），直接被滑掉。
  - `## 第三種地方：有共同活動的場合`：運動、社團、課程、朋友的聚會。那裡靠「你這個人」，不靠照片。
  - `## 只在一個地方聊得好，不是你擅長那裡`：是你只敢待在那裡。多去一個你不熟的場合，就多一種練習。
  - `## 今天的練習`：找一個這個月可以參加的、有共同活動的場合，報名。
- **不能寫**：教人在職場怎麼曖昧。職場那段只講「別在那裡做」。

### 4.6 id 36｜傳訊息之前，先看一下自己的心情

- **一句話**：你的狀態會傳給她；為了討她的反應而說的話會變質；狀態不好可以先不傳。
- **欄位**：核心社交心法／yellow／5 分鐘／`article_36.jpg`／練習卡：穩住自己（分類預設）。
- **大綱**
  - `## 心情會傳染`：帶著被主管罵完的情緒去聊，她收到的就是那個情緒。
  - `## 傳之前先問一句：我是想分享，還是想被安慰`：想被安慰的訊息，讀起來都像在索取。
  - `## 為了她的反應而說，話會變質`：背來的句子為什麼沒用，因為你在等她的好反應，她感覺得到。教練給的是方向，不是台詞。
  - `## 為自己開心而說`：你覺得有趣就分享；她沒接，換回普通聊天，不補問「很好笑吧」。
  - `## 狀態不好的時候，可以先不傳`：先照顧自己，往往比再找一句技巧有用。
  - `## 今天的練習`：下次想傳訊息前停十秒，問自己「我現在是想分享，還是想確認她還在不在」。
- **不能寫**：貶低教練的建議；「話術都沒用」這種絕對句。
