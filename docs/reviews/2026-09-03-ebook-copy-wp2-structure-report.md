## 一句話

只動結構、不動意思：把 HTML 轉手機後留下的「A｜B」管線表格改成清單、對照或可勾自評；補回第 3 冊 3.1 的五層與第 4 冊 4.5 的週次標題；畢業標準統一成 goal callout；一個 callout 塞好幾段的拆開；「課本 6.1／階段 2.6／類型 A／見第六節」這類 App 內看不懂的指涉改成冊章或前往按鈕；刪掉三個重複或錯位的段落。知識順序、數值規則、案例 A–N 一個都沒動。

## 怎麼做的

- 依 block id 逐一改正式 JSON（`assets/learning/ebooks/book_1..4`），第 5–7 冊 0 變動。改完跑 `normalize_ebook_copy.py --write`，把腳本組出來的字串裡 9 處括號旁的半形空白清掉（`--check` 回到 0 diff）。
- 每個殘留問題（第 1 冊 1.5 的英文代碼、第 2 冊 2.1 的 glossary 名稱、「假定同意」等禁用詞、定稿句缺漏）都留在原本的 block id 上，不換身分；所以 `--baseline` 新發現 0，baseline 只縮小。
- 新加的區塊全部在 field 級長度門檻內（bullet 100、paragraph 120、callout 160 字）。
- 依 ADR #45 第 7 點，純結構變動不升 `contentVersion`；閱讀進度以 block id 為 key，改型別不改 id 的區塊進度沿用，新 id 視為未讀。
- 這次沒有把一次性的改寫腳本放進 repo：正式 JSON 就是真源，diff 本身是紀錄；reviewer 用 `compare_ebook_import.py --official <工作包 1 的七冊> --candidate assets/learning/ebooks` 可以重算下面的新增／刪除／型別變動清單。
